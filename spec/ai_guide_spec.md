# AI 直译与导读质量规范（ai_guide_spec.md）——生成 + 量化评估

> **版本**：v1.0（2026-08-27；采纳双 AI 对 XSH 卷 2 章导读/译文的一轮评审：截断修复、XBD 首现注解、深水区条款完整直译、技术细节铁律、量化评分表）
> **适用**：三兄弟的**中文直译（老二）**与 **AI 导读（老三）** 的内容质量——生成时遵守、验收时按第 4 节评分。

> **执行区隔**：标有 **[Agent 执行]** 或"必须/禁止/铁律"的条目是硬性约束；评分表是量化验收工具。

## 1. 直译完整性铁律（Issue 8 深水区条款，缺一不可）

以下条款是 POSIX.1-2024（Issue 8）中**易被简化/省略、但省略即改变规范语义**的内容。直译时**必须完整译出**（对照原文逐成分核对），不得精简为"大意"：

1. **[Agent 执行] 信号处理程序对静态/线程存储期对象的访问（XSH 2.4.3）**：
   - 完整语义：处理程序引用"非无锁原子对象、非不可修改对象"的静态/线程存储期对象时，**除非"对该对象的前一次修改（如有）先行发生于（happens before）处理程序被调用，且处理程序返回先行发生于对该对象的下一次修改（如有）"，否则行为未定义**。
   - 常见错误：只写"不是无锁原子对象就是未定义行为"，丢掉 Happens-Before 时序前置条件 → **必须补全**。
2. **[Agent 执行] 断开流（broken pipe）上的 SIGPIPE 抑制（XSH 2.10）**：
   - 完整语义：对已断开流发送数据产生 `SIGPIPE`；用 `MSG_NOSIGNAL` 标志调用 `send()`/`sendto()`/`sendmsg()` 时信号被抑制；**但无论信号是否被抑制，发送操作都应失败并置 `errno` 为 `[EPIPE]`**（不得让人误以为抑制信号后调用成功）。
   - 常见错误：只写"信号被抑制"，漏掉"操作仍失败 + EPIPE" → **必须补全**。
3. **[Agent 执行] 功能测试宏版本号（XSH 2.2.1）**：
   - `_XOPEN_SOURCE` 的 XSI 版本值在 Issue 8 为 **800**（旧 Issue 7 为 700）；`_POSIX_C_SOURCE` 对应 **202405L**。
   - 直译/导读必须写明**当前版本的值**，并在导读易错点提示 700→800 迁移（老代码沿用 700 会隐藏新扩展符号）。
4. **[Agent 执行] FILE 对象不可复制（XSH 2.5）**：
   - `FILE` 对象内含可重入锁（`flockfile` 语义），**地址具有唯一标识性**；副本（`memcpy`/结构体赋值产生）的同步锁状态与文件描述符映射失效，不能代替原件使用。
   - 直译按原文（"副本不必可代替原件使用"）；**导读必须升级为硬性警戒**（严禁复制 FILE 对象），防止读者写出 memcpy FILE 的破坏性代码。
5. **术语首现注解**：卷缩写 `XBD`（Base Definitions，基础定义卷，含头文件声明与基础概念）、`XSH`、`XCU`、`XRAT` 在**首次出现时给一句话注解**（导读总览或首次出现处）。
6. **`errno` 异步信号安全（2.3/2.4）**：提及"信号处理程序读写 errno 是异步信号安全"时，**必须**给出保存/恢复范式（进入时 `int save_errno = errno;`，返回前 `errno = save_errno;`），并附代码示例。

## 2. 导读生成规范（每节结构 + 技术铁律）

### 2.1 结构（与直译严格镜像）

- 标题铁律与 `spec.md` 5.2 / `md_spec.md` 6 一致：0. 章节自由；从 1. 起与原文编号一一对应（`中文 (English)`）；细分用无编号粗体。
- **完整性检查（[Agent 执行]）**：正文**严禁尾部截断/语句断裂**；输出前必须重读结尾，确认以完整句收尾。历史教训：2.4.3 节曾出现"如果处理函数的执行不是由'显式…"断句，属不合格输出。

### 2.2 每节内容骨架

每节至少覆盖：**为什么存在 → 核心机制 → 易错点 → 跨节关联**（`spec.md` 5.3）；末尾可加 `**延伸阅读**`。

### 2.3 技术细节铁律（提到即必须写全）

| 主题 | 铁律内容 |
| --- | --- |
| 同步故障信号（`SIGSEGV`/`SIGBUS` 等） | 从处理程序正常 `return` 是未定义行为；正确处理路径是 `_exit()`/`abort()`/`siglongjmp()`（**不得只写"返回是 UB"不写怎么办**） |
| 套接字超时错误码 | `SO_RCVTIMEO`/`SO_SNDTIMEO` 超时返回 `[EAGAIN]`/`[EWOULDBLOCK]`；**提示两者在不同实现可能取值相同**，跨平台用 `errno == EAGAIN \|\| errno == EWOULDBLOCK` |
| `errno` 保存/恢复 | 见 1.6 |
| 分类/清单类内容 | **优先用对比表**（异步信号安全清单 / 线程安全例外清单 / 取消点清单等），减少冗长文本 |

### 2.4 三大清单速查（XSH 2 章导读总览建议包含）

| 清单名称 | 所在章节 | 核心防范目标 | 典型代表 | 违反后果 |
| --- | --- | --- | --- | --- |
| 异步信号安全函数 | 2.4.3 | 防中断上下文破坏主线程可重入状态 | `_exit`、`read`、`write`、`sem_post` | 未定义行为（死锁、堆损坏） |
| 线程安全例外函数 | 2.9.1 | 防多线程并发读写共享/静态缓冲区 | `strtok`、`localtime`、`getenv`、`rand` | 数据竞争、缓冲区踩踏 |
| 取消点函数 | 2.9.5 | 确定延迟取消的生效位置 | `read`、`write`、`pthread_cond_wait`、`select` | 线程资源泄漏或提前终止 |

## 3. 生成时 Checklist（[Agent 执行]，写完逐项自查）

1. □ 标题编号与直译/原文一一对应（无漏、无自造、无双重编号）
2. □ 全文无截断、无语句断裂、无残留占位符（`<!--MORE-->` 等）
3. □ 深水区条款完整（§1 清单 1-4）：Happens-Before、MSG_NOSIGNAL+EPIPE、版本号 800/202405L、FILE 不可复制
4. □ 卷缩写首现有注解（XBD/XSH/XCU/XRAT）
5. □ 信号处理相关代码示例含 errno 保存/恢复
6. □ 同步故障信号给出正确处理路径（`_exit`/`abort`/`siglongjmp`）
7. □ `EAGAIN`/`EWOULDBLOCK` 兼容性提示
8. □ 分类/清单用对比表
9. □ 无编造规范未提及的事实（不确定的语义宁可写"见原文 §x"）
10. □ 语言流畅自然、非翻译腔

## 4. 量化评估清单（验收评分表，总分 100）

> 用途：对任一中文直译/导读产物做**可量化的质量评估**。机检项用脚本/正则；人工项由评估者逐条打分。**≥90 优秀，80–89 合格，<80 需返工**。

### A. 结构完整性（机检，30 分）

| # | 检查项 | 检测方法 | 分值 |
| --- | --- | --- | --- |

| A2 | 无截断/无残留占位符/无双重编号/无"导读第 X 节"式标题 | `grep` 残留标记 + 结尾完整性人工确认 | 8 |

| # | 检查项 | 说明 | 分值 |
