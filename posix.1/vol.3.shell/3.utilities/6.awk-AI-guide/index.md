# awk 工具 AI 导读

> 本导读基于 POSIX.1-2024《Shell & Utilities》卷 *awk* 实用程序页面（`3.utilities/6.awk/index.md` 英文镜像及其中文直译）整理，只使用规范页面中的事实。配套阅读：镜像 [index.md](../6.awk/index.md)、中文直译 [index.md](../6.awk-translate/index.md)。

## 1. 核心概念

### 记录-字段模型（record-field model）

- 输入被解释为一系列**记录（record）**。默认一条记录是一行（去掉结尾换行符），可用内置变量 `RS` 改变。
- 每条记录被解释为一系列**字段（field）**。默认字段是由非空白、非换行字符组成的字符串，可用 `FS` 内置变量或 `-F sepstring` 选项改变。
- 第一个字段是 `$1`，第二个是 `$2`，依此类推；`$0` 指整个记录。
- **给任何其他字段赋值会导致 `$0` 重新求值；给 `$0` 赋值会重置所有其他字段和 `NF` 的值。**

### 模式-动作（pattern-action）执行模型

- 一个 awk 程序是一系列**模式（pattern）**及与之对应的**动作（action）**：`pattern { action }`。模式或动作可以省略：缺模式匹配任何记录，缺动作等价于 `{ print }`。
- 输入记录被读入后：先按当时 `FS` 的值把记录拆成字段（在第一次引用字段之前）；然后按出现顺序对每个模式求值，对每个匹配当前记录的模式执行其动作（匹配模式的动作在当前记录上执行完毕后，才继续求值后续模式）。
- 字段拆分使用**读取该记录时 `FS` 的当前值**。

### BEGIN / END

- 程序执行：先按出现顺序执行所有 `BEGIN` 模式的关联动作；然后逐个处理输入文件；最后按出现顺序执行所有 `END` 动作。
- `BEGIN` 动作在读取第一条输入记录之前、命令行赋值完成之前执行（但先前的 `BEGIN` 动作中可通过 `getline` 读输入）。
- `END` 动作在最后一条输入记录读完后执行；`nextfile` 之后若无更多输入文件也会触发 `END`。
- 只含 `BEGIN` 动作且不含 `getline` 的程序：最后一个 `BEGIN` 动作的最后一条语句执行完即退出、不读输入；只含 `END`（或 `BEGIN`+`END`）的程序：先读输入再执行 `END`。
- `BEGIN`/`END` 不与其他模式组合；可多个；`END` 可出现在 `BEGIN` 之前；二者必须有动作。

## 3. 内置函数分组速查

### 算术函数（页面：算术函数 (Arithmetic Functions)）

| 函数 | 作用 |
|---|---|
| `atan2(y, x)` | 返回 y/x 的反正切（弧度），范围 [-ℼ,ℼ] |
| `cos(x)` / `sin(x)` | 余弦 / 正弦，x 以弧度计 |
| `exp(x)` | 指数函数 |
| `log(x)` | 自然对数 |
| `sqrt(x)` | 平方根 |
| `int(x)` | 截断为整数（x>0 时向 0 截断） |
| `rand()` | 伪随机数 n，0<=n<1 |
| `srand([expr])` | 设置 `rand` 种子（省略用 Epoch 秒数），返回旧种子；expr 非整数或不在 0..2^31-1 内行为未指定；相同种子重现相同序列 |

### 字符串函数（页面：字符串函数 (String Functions)）

| 函数 | 作用 |
|---|---|
| `index(s, t)` | t 在 s 中首次出现的位置（1 起），无则 0 |
| `length[( [arg] )]` | arg 为数组时返回元素个数；否则返回字符串长度（字符数）；无参数返回 `$0` 长度 |
| `match(s, ere)` | ere 在 s 中的位置（1 起），无则 0；设置 `RSTART`/`RLENGTH` |
| `split(s, a [, fs])` | 按 ERE fs（缺省 `FS`）拆分 s 到 a[1..n]，返回 n；先清空数组 |
| `sprintf(fmt, expr, ...)` | 按 printf 格式格式化并返回字符串 |
| `substr(s, m [, n])` | s 从 m 起至多 n 字符的子串（1 起） |
| `tolower(s)` / `toupper(s)` | 按 `LC_CTYPE` 映射大小写 |
| `sub(ere, repl [, in])` | 替换 in（缺省 `$0`）中 ere 第一次出现，返回替换次数；repl 中 `&` 表示匹配文本，`\&` 为字面 &，`\\` 为字面 \；in 必须为 lvalue |
| `gsub(ere, repl [, in])` | 同 sub 但替换所有出现 |
| `gensub` | 页面未定义（GNU 扩展，不在 POSIX 页面） |

### 输入/输出与通用函数（页面：输入/输出与通用函数 (Input/Output and General Functions)）

| 函数/形式 | 作用 |
|---|---|
| `print [expr_list] [redirection]` | 输出表达式（缺省 `$0`），用 OFS 分隔、ORS 终止 |
| `printf format [, args] [redirection]` | 格式化输出（详见页面 10 条例外） |
| `getline` | `$0`=当前文件下一条记录；设置 NF、NR、FNR |
| `getline var` | var=当前文件下一条记录；设置 FNR、NR |
| `getline [var] < expression` | 从命名文件读下一条记录 |
| `expression \| getline [var]` | 从命令管道读一条记录 |
| `close(expression)` | 关闭同名（相同字符串值）文件/管道；成功 0，失败非零 |
| `fflush([expression])` | 冲刷同名文件/管道流；无参或空串则全部冲刷；成功 0 |
| `system(expression)` | 执行命令并返回其退出状态 |

- 所有形式 `getline`：成功输入返回 1，EOF 返回 0，出错返回 -1。
- 字符串作为文件/管道名时必须**文本上完全相同**："相同字符串值"意味着仅差空格的"等价字符串"表示不同文件。

### 位运算

- `and`、`or`、`xor`、`compl`、`lshift`、`rshift`：**页面未定义**（GNU awk 扩展，不在 POSIX 规范中）。

## 4. 正则表达式要点

- 使用扩展正则表达式（ERE，见 XBD 9.4），并允许 C 语言风格转义：`\\`、`\a`、`\b`、`\f`、`\n`、`\r`、`\t`、`\v`，以及页内表：`\"`（STRING 内为双引号）、`\/`（ERE 内为斜杠）、`\ddd`（八进制字符，全 0 或 >\377 未定义）、`\.` `\[` `\(` `\*` `\+` `\?` `\{` `\|` `\^` `\$`（ERE 内表示自身）、`\\`、`\c`（其他字符，未定义）。
- 匹配运算符 `~` 与 `!~`：右操作数为正则，左操作数为字符串；匹配为 1 / 0。
- 右操作数若不是 ERE token 而是字符串表达式，其字符串值被解释为正则表达式；字符串字面量的转义在词法上先处理一次、作为正则再处理一次（**双重转义**）。
- 单独出现（非 `~`/`!~` 右侧、非函数参数）的 `/ere/` 等价于 `$0 ~ /ere/`。
- `gsub`/`match`/`sub` 的 ere 参数、`split` 的 fs 参数都可为 ERE token 或任意表达式。
- 针对输入记录匹配时：记录分隔符字符（RS 第一个字符）不能被匹配、不能嵌入模式；针对文本串匹配时任何字符（含换行、分隔符）都可匹配。模式、记录或文本中出现 NUL 产生未定义结果。
- `FS` 行为：空串未指定；单字符时若是空格则按空白/换行集合切分（跳过前导尾随空白），否则按该字符每次出现切分；多字符按 ERE 切分。

## 5. 控制流速查

- `if (expr) stmt [else stmt]`、`while (expr) stmt`、`do stmt while (expr)`、`for (init; cond; incr) stmt`、`for (var in array) stmt`（迭代顺序未指定；循环内新增元素结果未定义）、`break`、`continue`（循环外使用未定义）。
- `delete array[index]` 删除单个元素；`delete array` 删除全部元素（`for...delete array[i]` 等价）。
- `next`：放弃当前记录的所有进一步处理；出现在/被调用于 BEGIN、END 动作中行为未定义。
- `nextfile`：放弃当前文件的所有进一步处理；出现在 BEGIN/END 或用户定义函数中行为未定义。
- `exit [expr]`：按序调用所有 END 动作后终止；END 内的 exit 不再执行其余 END；expr 数值为退出状态（除非之后出错或再执行带表达式的 exit）。
- `return [expr]`：函数内返回值；函数外使用未定义。
- 布尔上下文：有数值时 0 为假、非 0 为真；否则空串为假、非空为真。
- 比较：双方为数值、一方数值另一方数值字符串、双方数值字符串、一方数值另一方未初始化 → 数值比较；否则字符串比较（`!=`/`==` 比较是否相同，其他运算符按 locale 整理序列）。

## 6. 选项与命令行赋值语义

- `awk [-F sepstring] [-v assignment]... program [argument...]`
- `awk [-F sepstring] -f progfile [-f progfile]... [-v assignment]... [argument...]`
- `-F sepstring`：定义输入字段分隔符，等价于 `-v FS=sepstring`；若两者都用，`-F` 产生的 FS 赋值按命令行顺序处理还是排在最后一个是**未指定**的。
- `-f progfile`：程序文件路径名；`'-'` 表示标准输入；多次指定时按顺序连接各文件内容作为程序。
- `-v assignment`：形式须与 assignment 操作数相同；在**执行程序（包括 BEGIN 动作）之前**生效；可多次。
- `program` 操作数：无 `-f` 时第一个操作数是程序文本；文本不以换行结尾时按"以换行结尾"解释。
- `argument` 两种：`file`（输入文件路径名，`'-'` 为标准输入）；`assignment`（以 `_` 或字母开头、含 `_`/数字/字母、后跟 `=`；名称是保留字则未定义；`=` 后的字符按 STRING token 解释，末字符为未转义反斜杠时按字面反斜杠）。若名称是保留字行为未定义。
- **赋值时机**：每个赋值恰好在处理下一个 file 之前发生 → 第一个 file 之前的赋值在 BEGIN 动作**之后**执行；最后一个 file 之后的赋值在 END 动作**之前**执行；无 file 参数时在处理标准输入之前执行。
- 操作数赋值也可通过修改 `ARGV`/`ARGC` 达到等价效果；BEGIN 动作处理完后 awk 按内部计数器遍历 `ARGV`（空串元素跳过、符合赋值格式的处理赋值、其余按 file 处理）。

## 7. 典型用法示例（取自页面示例）

```sh
awk '$3 > 5'                       # 输出字段 3 大于 5 的所有行
awk '(NR % 10) == 0'               # 每第十行
awk '$2 ~ /xyz/ && $4 !~ /xyz/'    # 第 2 字段匹配 xyz 且第 4 字段不匹配的行
awk '{ print $2, $1 }'             # 交换前两个字段输出
awk '{s += $1} END {print "sum is", s, "avg is", s/NR}'   # 求和与平均
awk 'BEGIN { n = split(ENVIRON["PATH"], path, ":"); for (i=1; i<=n; ++i) print path[i] }'  # PATH 前缀
awk -f program n=5 input           # -f 程序文件 + 命令行赋值 n=5
```

命令行内嵌程序常用单引号包裹（awk 程序常含对 shell 特殊的字符，如双引号）；程序含单引号时用 shell 拼接：`awk '/'/ { print "quote:", $0 }'`。

## 8. 易错点（均有页面依据）

1. **字段重赋值导致 `$0` 重算**：设置 `$1`.. 等任何字段会触发 `$0` 重新求值；给 `$0` 赋值重置所有字段与 `NF`。对不存在的字段（`$NF` 之后）赋值（如 `$(NF+2)=5`）会增大 `NF`、创建中间字段（未初始化值）并按 `OFS` 重算 `$0`；但**引用**不存在的字段不创建新字段，只求值为未初始化值。
2. **数值字符串比较**：仅来自特定来源（字段、getline 输入、FILENAME、ARGV/ENVIRON 元素、split 结果、命令行赋值、来自数值字符串变量的赋值）且满足 strtod/词法 NUMBER 条件的字符串才是数值字符串；否则按字符串比较。`if (0 == "000")` 这类比较按数值进行（页面原理节明确讨论）。`"=="`/`"!="` 检查字符串是否**相同**而非整理相等；要测整理相等用 `a <= b && a >= b`。
3. **FS 为空格时的特殊切分**：`FS` 是单个空格时，跳过前导/尾随空白和换行，字段由**一个或多个**空白/换行集合分隔（即连续空白不产生空字段）；`FS` 为其他单字符时按每次出现切分（连续出现产生空字段）；空串 `FS` 行为未指定；多字符按 ERE。
4. **/regex/ 与字符串正则的双重转义**：字符串字面量的 `\` 转义先被词法处理一次，用作正则时再解释一次。例：匹配反斜杠用 `$2 ~ /\\/`（ERE 内 `\\` 表示一个反斜杠）；用字符串则需 `$2 ~ "\\\\"`（页面示例 6/7）。
5. **getline 的多种形式与副作用**：无 var 形式设置 `$0` 与 `NF`（及 `NR`/`FNR`）；`getline var` 只设 var（及 `NR`/`FNR`）；管道/重定向形式同名表达式共享同一打开流直到 `close`。`|` 左侧、`<` 右侧有未加括号运算符时产生**歧义结构**（结果未指定），必须加括号。`getline` 返回 1/0/-1。
6. **BEGIN 内变量**：`FILENAME` 在 BEGIN 内未设置；`NF` 在 BEGIN 内除非先前执行过无 var 的 `getline` 否则使用未定义；`NR`/`FNR` 在 BEGIN 内为 0。
7. **`-F` 与 `-v FS=` 同时使用的顺序**未指定；`-v` 赋值在 BEGIN 之前、操作数赋值在 BEGIN 之后（处理下一个文件前），两者时机不同。
8. **`exit` 与退出状态**：`exit expr` 的 expr 数值成为退出状态；END 动作内的 exit 终止程序不再执行其余 END。默认退出状态：0 = 所有输入文件成功处理；>0 = 出错；只含 BEGIN 且无 getline 的程序执行完直接退出不读输入。
9. **字符串用作文件/管道名的"同一性"**：必须文本完全相同；仅差空格的字符串被视为不同文件。
10. **`length()` 的两种含义**：无参数= `$0` 长度；数组参数=元素个数（Issue 8 规定）。
11. **`sub`/`gsub` 的 repl**：`&` 是匹配文本；要字面 `&` 用 `\&`；repl 为字符串字面量时转义先被词法处理（页面示例：`gsub(ERE, "\\&")` 产生一个字面 `&`）。
12. **保留字/语法细节**：函数名与 `(` 之间不能有空白（否则是 FUNC_NAME 与普通调用的区分）；`else` 与最近 `if` 关联；ERE 与除法 `'/'` 的歧义按"除法运算符优先"解决；`$x++--` 因 `$` 优先级高于 `++` 不是有效表达式。
