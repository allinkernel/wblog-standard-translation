sed 实用程序 AI 导读

本导读基于 POSIX.1-2024《Shell & Utilities》卷中 sed（流编辑器）标准页面的内容整理，全部事实均出自该页面，未作发挥。

1. 核心概念

1.1 流式编辑模型

sed 是一个流编辑器（stream editor）：它读取一个或多个文本文件，根据一个编辑命令脚本进行编辑修改，并将结果写入标准输出。它不提供交互式编辑，而是”一次一行”地处理输入流。

  • 脚本来源：script 操作数字符串，或 -e script 与 -f script_file 选项参数的组合。
  • 输入文件应为文本文件；未指定 file 操作数时使用标准输入；多个文件按指定顺序读取并拼接后一起编辑（行号跨文件累计）。

1.2 模式空间（pattern space）与保持空间（hold space）

  • 模式空间：sed 每周期把一行输入（去掉行尾换行符）放入模式空间，所有命令都作用于它。周期结束（或命令显式开始新周期）时，模式空间被复制到标准输出（除非指定 -n），然后被删除。
  • 保持空间：辅助缓冲区，用于保存模式空间的全部或部分内容供后续取回。命令 h/H 写入保持空间，g/G 从保持空间取回，x 交换两者。
  • 两者各应能容纳至少 8192 字节。

1.3 脚本执行模型

  1. 读入一行（去掉行尾换行符）放入模式空间。
  2. 按顺序应用所有地址选中该模式空间的命令。
  3. 直到某个命令开始下一个周期（如 d、D、c）或退出（如 q）。
  4. 若没有任何命令显式开始新周期，则脚本末尾将模式空间复制到标准输出（-n 时除外）并删除之，然后读下一行。
  5. 若上一周期由 D 命令结束且模式空间中残留换行符，则跳过”从输入读取”这一步（继续处理残留内容）。
  6. 每当模式空间被写入标准输出或命名文件时，sed 立即在其后跟一个换行符。

命令形式：[address[,address]]function，其中 function 是单字符命令动词。命令前可有空白/分号字符，函数前可有空白字符。

2. 地址寻址（Addresses in sed）

地址形式 含义
十进制数字 行号，跨文件累计计数输入行
$ 最后一行输入
/RE/ 或 \cREc 上下文地址：RE 是正则表达式，c 是除反斜杠或换行符外的任意定界符（如 \x...x）
  • 无地址：选中每个模式空间。
  • 一个地址：选中每个匹配该地址的模式空间。
  • 两个地址（addr1,addr2）：选中闭区间——从匹配第一个地址的第一个模式空间起，到匹配第二个地址的下一个模式空间止。若第二个地址是小于等于首行行号的数字，则只选中一行。区间结束后，从区间后第一行开始重新查找第一个地址，如此反复。
  • 否定 !：函数前可加 !，表示地址未选中模式空间时才应用该函数。! 前可接受空白，符合要求的应用不应在 ! 后跟空白字符。
  • 省略地址分量（如 ,addr 或 addr,）产生未定义结果。
  • 上下文地址中的转义："/abc\/def/" 中第二个 / 表示字面斜杠，RE 实为 abc/def；"\xabc\xdefx" 同理，RE 为 abcxdef。转义序列 \c 不会终止 RE。

3. 命令集速查表

本页实际出现的命令如下（含 {} 分组、空命令、# 注释）。[2addr] 等表示该命令允许的最大地址数。

命令 地址 语义与注意事项
{ … } [2addr] 命令组：仅当模式空间被选中时执行括号内的一组编辑命令；右花括号前须有换行或分号
a\ 文本 [1addr] 将文本安排到稍后输出（见下”输出时机”）
b [label] [2addr] 分支到带 label 的 : 命令；无 label 则分支到脚本末尾
c\ 文本 [2addr] 删除模式空间；0/1 地址或在两地址区间末尾时把文本放到输出上；开始下一个周期（注意：区间内每一行都会触发新周期）
d [2addr] 删除模式空间并开始下一个周期
D [2addr] 模式空间无换行符：等同 d；否则删除到第一个换行符为止的初始段，用剩余内容开始下一周期，不读新输入
g [2addr] 用保持空间内容替换模式空间内容
G [2addr] 向模式空间追加一个换行符加保持空间内容
h [2addr] 用模式空间内容替换保持空间内容
H [2addr] 向保持空间追加一个换行符加模式空间内容
i\ 文本 [1addr] 将文本写入标准输出
l [2addr] 以视觉无歧义形式输出模式空间：可打印转义序列（\\、\a、\b、\f、\r、\t、\v）；其他不可打印字符按字节写为三位八进制（前加反斜杠）；长行折叠处写 \ + 换行；行尾用 $ 标记
n [2addr] 默认输出未被抑制时先写模式空间到标准输出，再用下一行输入替换模式空间；无下一行则分支到脚本末尾退出（不开始新周期）
N [2addr] 把下一行输入（去行尾换行符）追加到模式空间，中间用嵌入换行符分隔；当前行号会改变；无下一行则退出（不写模式空间）
p [2addr] 将模式空间写入标准输出
P [2addr] 将模式空间写到第一个换行符为止的部分写入标准输出
q [1addr] 分支到脚本末尾并退出，不开始新周期
r rfile [1addr] 把 rfile 内容复制到标准输出（安排到稍后输出）；文件不存在或不可读按空文件处理，不报错
s/RE/replacement/flags [2addr] 用替换串替换模式空间中 RE 的实例（详见下文）
t [label] [2addr] 测试：自最近一次读入输入行或执行 t 以来若有任何替换发生，则分支到带 label 的 : 命令；无 label 分支到脚本末尾
w wfile [2addr] 将模式空间追加（写入）到 wfile
x [2addr] 交换模式空间与保持空间的内容
y/string1/string2/ [2addr] 把 string1 中每个字符替换为 string2 中对应字符；\n 两字符序列视为单个换行符；两串字符数不等或 string1 有重复字符则结果未定义
:label [0addr] 空操作，作为 b、t 分支的标签
= [1addr] 向标准输出写 "%d\n", <当前行号>
（空命令） [0addr] 忽略
# [0addr] 注释：忽略 # 及行余下部分；唯一例外是脚本开头两个字符为 #n 时抑制默认输出（等同命令行 -n）

3.1 s 命令细节

  • 定界符：除反斜杠或换行符外的任意字符（不限于 /），如 s:RE:replacement:g；转义序列第二字符位置的定界符不终止 RE/替换。
  • 替换串：& 表示匹配 RE 的整段文本（\& 可转义为字面 &）；\n（n 为数字）表示第 n 个反向引用匹配的文本，未匹配则为空串；行内可替换入换行符（须写成 \ + 换行）来拆分一行。
  • flags：
    • n（数字）：只替换模式空间内第 n 次出现；
    • g：全局替换所有非重叠实例；g 与数字同时指定结果未指定；
    • i：不区分大小写匹配；
    • p：若发生替换则写模式空间到标准输出；
    • w wfile：若发生替换则把模式空间追加到 wfile；w 不是最后一个 flag 时结果未定义。
  • 即使替换结果与原文相同，也视为执行了一次替换（影响 t 的测试结果）。

3.2 a/r 的输出时机

a 的文本与 r 的文件内容属于”安排稍后输出”：在以下时机写入标准输出——执行 c、D、d、N、n 时下一次尝试获取输入行之前；执行 q 之前；或到达脚本末尾时（若未指定 -n，则在模式空间被复制到标准输出之后写入）。r 的文件内容以输出时的文件内容为准，且按 a/r 命令应用于输入的顺序输出。

3.3 其他规则

  • wfile 在处理开始前创建；脚本中至少支持十个 wfile 参数；wfile 参数会终止编辑命令。
  • label 超过 8 字节或含便携文件名字符集外字符时行为未指定。
  • 除 a、b、c、i、r、t、w、:、# 外的命令后可用分号再接另一个命令（s 带 w 标志时除外，结果未定义）。

4. 选项速查

选项 作用
-n 抑制默认输出；只输出脚本显式选中的行（配合 p、s/p 等）
-E 使用扩展正则表达式（ERE）匹配；默认是 BRE
-e script 把 script 中的编辑命令追加到脚本末尾
-f script_file 把 script_file 中的编辑命令追加到脚本末尾
  • 若指定了任何 -e/-f，脚本初始为空，按命令行呈现顺序依次追加；若前一次添加来自 -e 选项，则在新添加前插入一个换行符（即各 -e 的脚本用换行连接）。
  • 概要形式：sed [-En] script [file...]、sed [-En] -e script [-e script]... [-f script_file]... [file...]、sed [-En] [-e script]... -f script_file [-f script_file]... [file...]。
  • 注意：-e 与 -f 的呈现顺序有意义（这是对 XBD 12.2 实用程序语法准则的唯一例外）。

5. 典型用法示例（来自页面示例）

示例 1：压缩多余空白行（模拟 BSD cat -s）

sed -n '
# Write non-empty lines.
/./ {
    p
    d
    }
# Write a single empty line, then look for more empty lines.
/^$/    p
# Get next line, discard the held <newline> (empty line),
# and look for more empty lines.
:Empty
/^$/    {
    N
    s/.//
    b Empty
    }
# Write the non-empty line before going back to search
# for the first in a set of empty lines.
    p
'

要点：-n 抑制默认输出；p 显式输出；N 把下一行拼入模式空间（多行模式）；s/.// 吃掉拼接处产生的换行符；:Empty + b Empty 构成循环。

示例 2：更简单的空白行压缩（会移除开头的空白行）

sed -n '/./,/^$/p'

要点：两地址区间 /./,/^$/ 从非空行打印到空行，跨多个区间。

示例 3：p 标志与 -n 的配合（来自 RATIONALE）

echo a | sed    's/a/A/p'     # 输出两行 A（替换行 + p 行）
echo a | sed -n 's/a/A/p'     # 只输出一行 A（默认输出被抑制，仅 p 写出）

POSIX.1-2024 规定：第一个例子写两行 A，第二个写一行 A。

6. 易错点（均有页面依据）

  1. -n 与 p 的配合：-n 抑制默认输出后，必须靠 p、s/.../p、P 等命令显式输出；反之，不写 -n 时 s 的 p 标志会导致重复输出（如示例 3 的两行 A）。
  2. 模式空间被清空的时机：周期正常结束时模式空间被复制到标准输出然后删除；d、D、c 会提前清空并开始新周期；q 退出不再输出模式空间（但 a/r 排队的文本会在 q 前输出）。
  3. N/D/P 与多行模式：N 把下一行拼入模式空间后，模式空间含嵌入换行符；D 只删除到第一个换行符为止的部分并不读新输入继续下一周期；P 只输出到第一个换行符为止的部分。\n 转义序列可匹配模式空间中的嵌入换行符，但不能匹配输入行行尾的换行符（行尾换行符在读入时已被去掉）。
  4. 保持空间的交换：h/H 写、g/G 读、x 交换；G/H 是追加（先加一个换行符），多次追加会积累内容，注意与替换式 g/h 的区别。
  5. s 命令的寻址与 g 标志：默认只替换每行第一个匹配；g 替换所有非重叠实例；g 与数字 n 同时给出结果未指定；t 的”是否有替换发生”统计从最近一次读行或执行 t 算起。
  6. 地址区间跨文件行为：行号跨文件累计（多个 file 操作数拼接后统一编号）；$ 指拼接后整个输入的最后一行。
  7. c 命令的区间语义：c 在其地址区间匹配的每一行上都开始下一个周期（Issue 8 缺陷 1767 澄清），区间内每行都会触发。
  8. 定界符与转义：在 RE 中想用定界符的字面值，可将其放入括号表达式（如 \.[.][0-9]. 用 . 作定界符）；用反斜杠转义定界符是否保留特殊含义在实现间有差异；\ 与换行符不能用作定界符。
  9. # 注释与 #n：脚本前两个字符为 #n 时等价于命令行 -n，其余 # 行为注释被忽略。
  10. 空白字符处理：命令前可加空白；! 后不应跟空白；label 忽略前导空白但对尾随空白的历史行为不一（'x' 与 "x " 可能是不同标签）。

7. 与常见扩展的差异（页面提示）

  • 页面上没有 e（执行 shell 命令）或 Q（立即退出）命令；也没有 s 的 I 大写标志——但页面注明”一些实现”把大写 I 作为小写 i 的别名（非标准要求）。
  • 一些实现把正则表达式中的 \t 等当作 awk 风格转义（如 \s 匹配空白），这是兼容性扩展；在括号表达式内与本标准冲突，可移植应用应写两个反斜杠。
