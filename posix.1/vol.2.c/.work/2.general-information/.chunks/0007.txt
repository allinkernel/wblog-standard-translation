[h3_00807] [A819][/A819]2.6 File Descriptor Allocation
[p_00808] All functions that open one or more file descriptors shall, unless specified otherwise, atomically allocate the lowest numbered available (that is, not already open in the calling process) file descriptor at the time of each allocation. Where a single function allocates two file descriptors (for example, [A820][I821]pipe[/I821]()[/A820] or [A822][I823]socketpair[/I823]()[/A822]), the allocations may be independent and therefore applications should not expect them to have adjacent values or depend on which has the higher value.
