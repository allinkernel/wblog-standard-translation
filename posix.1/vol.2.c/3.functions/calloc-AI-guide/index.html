XSH 函数导读：calloc()

0. 总览

calloc() 是内存分配器：为具有 nelem 个元素、每元素 elsize 字节的数组分配未使用的空间，并把该空间初始化为所有位均为 0。头文件为 <stdlib.h>。原型关键点：void *calloc(size_t nelem, size_t elsize)——两个参数分别是元素个数与元素大小，总大小为二者乘积；成功返回指向所分配空间起始位置的指针，失败返回空指针并设置 errno。

1. 机制

分配的核心行为：calloc() 与 malloc() 的差别在于两点——按"元素个数 × 元素大小"计算总量，并且分配的空间全部清零（所有位为 0）。连续调用分配的存储顺序与连续性未指定；成功分配的存储与其他任何对象不相交。若 nelem 或 elsize 中任一为 0，行为是实现定义的：或者返回空指针，或者行为如同请求了非零大小，但此时用返回的指针访问对象行为未定义。当可用内存不足（包括 nelem * elsize 溢出）时返回 NULL 并设 [ENOMEM]；分配/释放同一区域的调用按单一全序发生，释放与下一次分配同步。

2. 易错点

常见坑：一是虽然 calloc() 清零了内存，但对所有位为 0 的解释要小心——规范只说"所有位均为 0"，并不保证浮点零或空指针的位模式必然如此（尽管常见实现如此）；二是参数顺序是 nelem, elsize，写反了语义一般仍等价于乘法，但可读性差且易与 reallocarray() 混淆；三是"清零"并不等于"初始化"，对结构体的指针成员仍需显式赋值；四是返回值仍必须判空，特别是大数组或乘法溢出场景；五是零大小分配返回的指针不可用于访问对象。

3. 示例

#include <stdlib.h>
#include <stdio.h>

int main(void) {
    int *a = calloc(10, sizeof(int));  /* 10 个 int，全部清零 */
    if (a == NULL)
        return 1;

    printf("%d\n", a[5]);   /* 0：calloc 已清零 */
    free(a);
    return 0;
}
