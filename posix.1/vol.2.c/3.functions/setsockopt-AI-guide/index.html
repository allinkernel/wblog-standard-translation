XSH 函数导读：setsockopt()

0. 总览

setsockopt() 设置套接字选项：在由 level 指定的协议层上，把由 option_name 指定的选项设置为 option_value 指向的值。头文件为 <sys/socket.h>，原型为 int setsockopt(int socket, int level, int option_name, const void *option_value, socklen_t option_len)。成功返回 0，失败返回 -1 并设置 errno。

1. 机制

level 指定选项所在协议层：套接字层选项置为 SOL_SOCKET（SO_ 选项始终存在于最顶层的套接字层）；其他层选项提供控制该选项的协议层标识符，例如由 TCP 解释的选项把 level 设为 <netinet/in.h> 中定义的 IPPROTO_TCP。option_value 和 option_len 给出选项的新值及其字节长度；选项类型各异（int、struct timeval、linger 结构等），必须按每个选项的约定提供正确类型。应用程序可用它分配缓冲区空间、控制超时（如 SO_RCVTIMEO、SO_SNDTIMEO）或允许套接字数据广播。设置 SO_RCVTIMEO/SO_SNDTIMEO 时，timeval 是按原样存储还是向上取整以对齐时钟分辨率，未指定；以 SO_ACCEPTCONN、SO_ERROR 或 SO_TYPE 为 option_name 调用 setsockopt() 时行为未指定，应改用 getsockopt() 读取这类只读选项。

2. 易错点

  • option_len 必须与选项实际类型匹配（如 int 选项传 sizeof(int)），传错大小或类型会导致错误或意外行为。
  • 套接字已连接时部分选项无法设置，返回 [EISCONN]；应在 bind()/connect() 之前完成此类设置。
  • 超时值太大放不进套接字结构中的超时字段时返回 [EDOM]。
  • 选项无效返回 [EINVAL]，协议不支持返回 [ENOPROTOOPT]，level 用错层是常见错误。
  • 被 accept()/accept4() 接受的套接字从侦听套接字继承哪些选项是实现定义的，需要特定设置时应直接对被接受的套接字调用 setsockopt()。

3. 示例

#include <sys/socket.h>
#include <netinet/in.h>

int one = 1;

/* 允许重用本地地址，需在 bind() 之前设置 */
if (setsockopt(sfd, SOL_SOCKET, SO_REUSEADDR,
               &one, sizeof(one)) == -1) {
    /* EINVAL、ENOPROTOOPT、EISCONN 等 */;
}
