XSH 函数：fflush()

[h4_00001] 名称 (NAME)

[blockquote_00002] fflush — 刷新流 (flush a stream)

[h4_00003] 提要 (SYNOPSIS)

[p_00004] #include <stdio.h>

int fflush(FILE *stream);

[h4_00005] 说明 (DESCRIPTION)

[CX] The functionality described on this reference page is aligned with the ISO C standard. Any conflict between the requirements described here and the ISO C standard is unintentional. This volume of POSIX.1-2024 defers to the ISO C standard.

[p_00006] 如果 stream 指向输出流或最近一次操作不是输入的更新流，则 fflush() 应使该流的任何未写入数据被写入文件，[CX] 并且底层文件的上次数据修改和上次文件状态更改时间戳应被标记更新。

[p_00007] 对于具有底层文件描述、为读取而打开的流，如果文件尚未位于 EOF，且该文件是能够寻位的文件，则底层打开文件描述的文件偏移量应被设置为流的文件位置，并且由 ungetc() 或 ungetwc() 压回流中、随后尚未从流中读出的任何字符应被丢弃（不再进一步更改文件偏移量）。

[p_00008] 如果 stream 是空指针，则 fflush() 应对上述为其定义了行为的所有流执行此刷新动作。

[h4_00009] 返回值 (RETURN VALUE)

[p_00010] 成功完成后，fflush() 应返回 0；否则，应设置流的错误指示符，返回 EOF，[CX] 并设置 errno 以指示错误。

[h4_00011] 错误 (ERRORS)

[p_00012] 在以下情况下，fflush() 函数应失败：

[dt_00013] [EAGAIN]
[dd_00014] [CX] 为 stream 底层的文件描述符设置了 O_NONBLOCK 标志，并且线程将在写操作中被延迟。
[dt_00015] [EBADF]
[dd_00016] [CX] stream 底层的文件描述符无效。
[dt_00017] [EFBIG]
[dd_00018] [CX] 试图写入超过最大文件大小的文件。
[dt_00019] [EFBIG]
[dd_00020] [CX] 试图写入超过进程文件大小限制的文件。 [XSI] 还应为该线程生成 SIGXFSZ 信号。
[dt_00021] [EFBIG]
[dd_00022] [CX] 该文件是普通文件，并且试图在或超出与相应流关联的偏移量最大值处写入。
[dt_00023] [EINTR]
[dd_00024] [CX] fflush() 函数被信号中断。
[dt_00025] [EIO]
[dd_00026] [CX] 进程是试图向其控制终端写入的后台进程组的成员，设置了 TOSTOP，调用线程未阻塞 SIGTTOU，进程未忽略 SIGTTOU，并且该进程的进程组是孤儿进程组。在实现定义的条件下也可以返回此错误。
[dt_00027] [ENOMEM]
[dd_00028] [CX] 底层流是由 open_memstream() 或 open_wmemstream() 创建的，且可用内存不足。
[dt_00029] [ENOSPC]
[dd_00030] [CX] 包含该文件的设备上或 fmemopen() 函数使用的缓冲区中没有剩余可用空间。
[dt_00031] [EPIPE]
[dd_00032] [CX] 试图写入没有任何进程为读取而打开的管道或 FIFO。还应向该线程发送 SIGPIPE 信号。

[p_00033] 在以下情况下，fflush() 函数可以失败：

[dt_00034] [ENXIO]
[dd_00035] [CX] 向不存在的设备发出了请求，或请求超出了设备的能力范围。
The following sections are informative.

[h4_00036] 示例 (EXAMPLES)

[h5_00037] 将提示发送到标准输出 (Sending Prompts to Standard Output)

[p_00038] 以下示例使用 printf() 调用来打印一系列提示，提示用户必须从标准输入输入的信息。fflush() 调用强制将输出写入标准输出。使用 fflush() 函数是因为标准输出通常被缓冲，提示可能不会立即打印在输出或终端上。getline() 函数调用从标准输入读取字符串，并将结果放入变量中，供程序稍后使用。

char *user;
char *oldpasswd;
char *newpasswd;
ssize_t llen;
size_t blen;
struct termios term;
tcflag_t saveflag;
 
printf("User name: ");
fflush(stdout);
blen = 0;
llen = getline(&user, &blen, stdin);
user[llen-1] = 0;
tcgetattr(fileno(stdin), &term);
saveflag = term.c_lflag;
term.c_lflag &= ~ECHO;
tcsetattr(fileno(stdin), TCSANOW, &term);
printf("Old password: ");
fflush(stdout);
blen = 0;
llen = getline(&oldpasswd, &blen, stdin);
oldpasswd[llen-1] = 0;
 
printf("\nNew password: ");
fflush(stdout);
blen = 0;
llen = getline(&newpasswd, &blen, stdin);
newpasswd[llen-1] = 0;
term.c_lflag = saveflag;
tcsetattr(fileno(stdin), TCSANOW, &term);
free(user);
free(oldpasswd);
free(newpasswd);

[h4_00039] 应用程序用法 (APPLICATION USAGE)

[p_00040] 无。

[h4_00041] 理由 (RATIONALE)

[p_00042] 系统缓冲的数据可能使确定当前文件描述符位置的正确性变得不切实际。因此，POSIX.1-2024 不强制要求在为 read() 打开的流上 fflush() 之后重新定位文件描述符。
