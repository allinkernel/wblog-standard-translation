XSH 函数：fstat()

名称 (NAME)

fstat — 获取文件状态 (get file status)

摘要 (SYNOPSIS)

#include <sys/stat.h>

int fstat(int fildes, struct stat *buf);

说明 (DESCRIPTION)

fstat() 函数应获取关于与文件描述符 fildes 关联的打开文件的信息，并将其写入 buf 所指向的区域。

[SHM] 如果 fildes 引用一个共享内存对象，实现应在 buf 参数所指向的 stat 结构中更新 st_uid、st_gid、st_size 和 st_mode 字段，并且只有 S_IRUSR、S_IWUSR、S_IRGRP、S_IWGRP、S_IROTH 和 S_IWOTH 文件权限位需要有效。实现可以更新其他字段和标志。

[TYM] 如果 fildes 引用一个类型化内存对象，实现应在 buf 参数所指向的 stat 结构中更新 st_uid、st_gid、st_size 和 st_mode 字段，并且只有 S_IRUSR、S_IWUSR、S_IRGRP、S_IWGRP、S_IROTH 和 S_IWOTH 文件权限位需要有效。实现可以更新其他字段和标志。

buf 参数是指向 stat 结构的指针，如 <sys/stat.h> 中所定义，关于文件的信息被放入该结构中。

对于本卷 POSIX.1-2024 中定义的所有其他文件类型，结构成员 st_mode、st_ino、st_dev、st_uid、st_gid、st_atim、st_ctim 和 st_mtim 应具有有意义的值，并且成员 st_nlink 的值应被设置为指向该文件的链接数。

提供附加或替代文件访问控制机制的实现可以在实现定义的条件下使 fstat() 失败。

fstat() 函数应在写入 stat 结构之前更新任何与时间相关的字段（如 XBD 4.12 文件时间更新 中所述）。

返回值 (RETURN VALUE)

成功完成后，应返回 0。否则，应返回 -1 并设置 errno 以指示错误。

错误 (ERRORS)

如果满足以下条件，fstat() 函数应失败：

[EBADF]
fildes 参数不是有效的文件描述符。
[EIO]
从文件系统读取时发生了 I/O 错误。
[EOVERFLOW]
以字节为单位的文件大小、分配给文件的块数或文件序列号无法在 buf 所指向的结构中被正确表示。

如果满足以下条件，fstat() 函数可以失败：

[EOVERFLOW]
其中一个值太大，无法存储到 buf 参数所指向的结构中。
The following sections are informative.

示例 (EXAMPLES)

获取文件状态信息 (Obtaining File Status Information)

以下示例展示了如何获取名为 /home/cnd/mod1 的文件的状态信息。为 stat 结构定义了结构变量 buffer。/home/cnd/mod1 文件以读/写权限打开，并被传给打开的文件描述符 fildes。

#include <sys/types.h>
#include <sys/stat.h>
#include <fcntl.h>
 
struct stat buffer;
int         status;
...
fildes = open("/home/cnd/mod1", O_RDWR);
status = fstat(fildes, &buffer);

变更历史 (CHANGE HISTORY)

首次发布于第 1 版。源自 SVID 的第 1 版。

第 5 版 (Issue 5)

DESCRIPTION（说明）已更新，以便与 POSIX 实时扩展保持一致。

添加了 Large File Summit 扩展。

第 6 版 (Issue 6)

在 SYNOPSIS（摘要）中，<sys/types.h> 头的可选包含已被移除。

对 POSIX 实现的以下新要求源自与单一 UNIX 规范（Single UNIX Specification）的一致性：

  • 包含 <sys/types.h> 的要求已被移除。虽然 <sys/types.h> 对先前 POSIX 规范的符合性实现是必需的，但它对 UNIX 应用程序不是必需的。

  • 添加了 [EIO] 强制性错误条件。

  • 添加了 [EOVERFLOW] 强制性错误条件。此更改是为了支持大文件。

  • 添加了 [EOVERFLOW] 可选错误条件。

DESCRIPTION（说明）已更新，通过规定共享内存对象语义适用于类型化内存对象，以与 IEEE Std 1003.1j-2000 保持一致。

第 7 版 (Issue 7)

应用了 XSH-SD5-ERN-161，更新了 DESCRIPTION（说明）以澄清 st_nlink 适用于哪些文件类型。

进行了与细粒度时间戳支持相关的更改。
