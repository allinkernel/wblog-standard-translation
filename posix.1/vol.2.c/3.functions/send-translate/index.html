XSH 函数：send()

名称 (NAME)

send — 在套接字上发送消息 (send — send a message on a socket)

摘要 (SYNOPSIS)

#include <sys/socket.h>

ssize_t send(int socket, const void *buffer, size_t length, int flags);

说明 (DESCRIPTION)

send() 函数应启动从指定套接字向其对端传输消息。只有在套接字已连接时，send() 函数才应发送消息。如果套接字是无连接模式的套接字，则消息应发送到预先指定的对端地址。

send() 函数接受以下参数：

socket
指定套接字文件描述符。
buffer
指向包含要发送的消息的缓冲区。
length
指定消息的长度（以字节为单位）。
flags
指定消息传输的类型。此参数的值通过对以下标志中的零个或多个进行逻辑或构成： MSG_EOR 终止一条记录（如果协议支持）。MSG_OOB 在支持带外通信的套接字上发送带外数据。带外数据的重要性和语义是特定于协议的。MSG_NOSIGNAL 请求在不再连接的面向流的套接字上尝试发送时不要发送 SIGPIPE 信号。仍应返回 [EPIPE] 错误。

要发送的消息的长度由 length 参数指定。如果消息太长而无法通过底层协议传递，send() 应失败，并且不应传输任何数据。

对 send() 调用的成功完成并不保证消息的送达。返回值为 -1 仅表示本地检测到的错误。

如果发送套接字处没有可用空间来容纳要传输的消息，并且套接字文件描述符未设置 O_NONBLOCK，则 send() 应阻塞，直到有空间可用或发生超时（参见 2.10.16 选项的使用 中的 SO_SNDTIMEO）。如果发送套接字处没有可用空间来容纳要传输的消息，并且套接字文件描述符确实设置了 O_NONBLOCK，则 send() 应失败。select() 和 poll() 函数可用于确定何时可以发送更多数据。

所使用的套接字可能要求进程拥有适当的权限才能使用 send() 函数。

返回值 (RETURN VALUE)

成功完成后，send() 应返回已发送的字节数。否则，应返回 -1，并设置 errno 以指示错误。

错误 (ERRORS)

在以下情况下，send() 函数应失败：

[EAGAIN] 或 [EWOULDBLOCK]
套接字的文件描述符被标记为 O_NONBLOCK，且请求的操作会阻塞。另请参见 2.10.16 选项的使用 中的 SO_SNDTIMEO。
[EBADF]
socket 参数不是有效的文件描述符。
[ECONNRESET]
连接被对端强制关闭。
[EDESTADDRREQ]
套接字不是连接模式的，且未设置对端地址。
[EINTR]
在传输任何数据之前，一个信号中断了 send()。
[EMSGSIZE]
消息太大，无法像套接字所要求的那样一次全部发送。
[ENOTCONN]
套接字未连接。
[ENOTSOCK]
socket 参数不引用套接字。
[EOPNOTSUPP]
socket 参数与一个不支持 flags 中设置的一个或多个值的套接字相关联。
[EPIPE]
套接字已关闭写入功能，或套接字是连接模式的且不再连接。在后一种情况下，如果套接字是 SOCK_STREAM 或 SOCK_SEQPACKET 类型且未设置 MSG_NOSIGNAL 标志，则向调用线程生成 SIGPIPE 信号。

在以下情况下，send() 函数可以失败：

[EACCES]
调用进程没有适当的权限。
[EIO]
在读取或写入文件系统时发生 I/O 错误。
[ENETDOWN]
用于到达目标的本地网络接口已关闭。
[ENETUNREACH]
不存在到达该网络的路由。
[ENOBUFS]
系统中可用于执行该操作的资源不足。
The following sections are informative.

示例 (EXAMPLES)

无。

应用程序使用 (APPLICATION USAGE)

如果 socket 参数引用的是连接模式的套接字，则 send() 函数等效于 sendto()（dest_addr 和 dest_len 参数可取任意值，因为在这种情况下它们被忽略）。如果 socket 参数引用的是套接字且 flags 参数为 0，则 send() 函数等效于 write()。
