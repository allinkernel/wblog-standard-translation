XSH 函数：strtok()

名称 (NAME)

strtok、strtok_r — 将字符串拆分为 token（标记）

提要 (SYNOPSIS)

#include <string.h>

char *strtok(char *restrict s, const char *restrict sep);

[CX] char *strtok_r(char *restrict s, const char *restrict sep,
char **restrict state);

说明 (DESCRIPTION)

对于 strtok()：[CX] 本参考页所述功能与 ISO C 标准一致。此处所述要求与 ISO C 标准之间的任何冲突均属无意。本卷 POSIX.1-2024 遵从 ISO C 标准。

对 strtok() 的一系列调用将 s 所指向的字符串拆分为一序列 token（标记），每个 token（标记）由 sep 所指向的字符串中的一个字节分隔。该序列中的第一次调用以 s 作为其第一个参数，随后是以空指针作为其第一个参数的调用。由 sep 所指向的分隔符字符串在每次调用之间可以不同。

该序列中的第一次调用在 s 所指向的字符串中搜索第一个不包含在由 sep 所指向的当前分隔符字符串中的字节。如果未找到这样的字节，则 s 所指向的字符串中没有 token（标记），且 strtok() 应返回空指针。如果找到这样的字节，它就是第一个 token（标记）的开始。

strtok() 函数随后从那里搜索包含在当前分隔符字符串中的字节。如果未找到这样的字节，则当前 token（标记）延伸到 s 所指向的字符串的末尾，且后续对 token（标记）的搜索应返回空指针。如果找到这样的字节，则用 NUL 字符覆盖它，该字符终止当前 token（标记）。strtok() 函数保存指向后续字节的指针，下一次 token（标记）搜索应从此指针开始。

随后的每次调用，以空指针作为第一个参数的值，从保存的指针开始搜索，并按上述方式运行。

实现应表现得如同本卷 POSIX.1-2024 中定义的任何函数都不调用 strtok()。

strtok() 函数不必是线程安全的；然而，strtok() 应避免与所有其他函数发生数据竞争。

[CX] strtok_r() 函数应与 strtok() 等价，不同之处在于 strtok_r() 应是线程安全的，并且参数 state 指向一个用户提供的指针，该指针允许 strtok_r() 在扫描同一字符串的调用之间维持状态。应用程序应确保 state 所指向的指针对于由 strtok_r() 调用并发处理的每个字符串（s）都是唯一的。应用程序不必将 state 所指向的指针初始化为任何特定值。实现不应更新 state 所指向的指针，使其（直接或间接地）指向 s 字符串内以外的、需要由调用方释放或解除的资源。

[CX] strtok() 和 strtok_r() 函数在有效输入上不应改变 errno 的设置。

返回值 (RETURN VALUE)

成功完成后，strtok() 应返回指向 token（标记）的第一个字节的指针。否则，如果没有 token（标记），strtok() 应返回空指针。

[CX] strtok_r() 函数应返回指向所找到的 token（标记）的指针，或者在未找到 token（标记）时返回空指针。

错误 (ERRORS)

未定义任何错误。

示例 (EXAMPLES)

搜索单词分隔符 (Searching for Word Separators)

以下示例搜索由 <space> 字符分隔的 token（标记）。

#include <string.h>
...
char *token;
char line[] = "LINE TO BE SEPARATED";
char *search = " ";
 
/* Token will point to "LINE". */
token = strtok(line, search);
 
/* Token will point to "TO". */
token = strtok(NULL, search);
在缓冲区中查找前两个字段 (Find First two Fields in a Buffer)

以下示例使用 strtok() 在由 buffer 所指向的字符数组的开头查找由 <space>、<tab> 或 <newline> 字符的任意组合分隔的两个字符串（一个键和与该键关联的数据）。

#include <string.h>
...
char    *buffer;
...
struct element {
    char *key;
    char *data;
} e;
...
// Load the buffer...
...
// Get the key and its data...
e.key = strtok(buffer, " \t\n");
e.data = strtok(NULL, " \t\n");
// Process the rest of the contents of the buffer...
...

应用程序使用 (APPLICATION USAGE)

注意，如果 sep 是空字符串，strtok() 和 strtok_r() 返回指向正在被 token（标记）化的字符串余下部分的指针。

strtok_r() 函数是线程安全的，并将状态存储在用户提供的缓冲区中，而不是可能使用可能被来自另一线程的不相关调用覆盖的静态数据区。

原理 (RATIONALE)

strtok() 函数在较大的字符串中搜索分隔符字符串。它返回指向分隔符字符串之间的最后一个子串的指针。该函数使用静态存储来跟踪调用之间的当前字符串位置。新函数 strtok_r() 接受一个附加参数 state，用于跟踪字符串中的当前位置。
