XSH 函数：getpid()

名称 (NAME)

getpid — 获取进程 ID (get the process ID)

概要 (SYNOPSIS)

#include <unistd.h>

pid_t getpid(void);

说明 (DESCRIPTION)

getpid() 函数应返回调用进程的进程 ID。

返回值 (RETURN VALUE)

getpid() 函数应始终成功，并且没有保留返回值来指示错误。

错误 (ERRORS)

未定义任何错误。
