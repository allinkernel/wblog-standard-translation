XSH 函数：realloc()

名称 (NAME)

realloc, reallocarray — 内存重新分配器

摘要 (SYNOPSIS)

#include <stdlib.h>

void *realloc(void *ptr, size_t size);

[CX] void *reallocarray(void *ptr, size_t nelem, size_t elsize);

说明 (DESCRIPTION)

对于 realloc()：[CX] 本参考页所述功能与 ISO C 标准对齐。此处所述要求与 ISO C 标准之间的任何冲突均属无意。POSIX.1-2024 本卷以 ISO C 标准为准。

realloc() 函数应释放 ptr 所指向的旧对象，并返回指向具有 size 所指定大小的新对象的指针。新对象的内容应与释放前的旧对象内容相同，直至新旧大小中较小者。新对象中超出旧对象大小的任何字节具有不确定的值。

[CX] reallocarray() 函数应等价于调用 realloc(ptr, nelem * elsize)，只是乘法中的溢出应视为错误。

若 ptr 是空指针，则 realloc() [CX] 或 reallocarray() 应等价于针对指定大小调用 malloc()。否则，若 ptr 与先前由 aligned_alloc()、calloc()、malloc()、[ADV] posix_memalign()、 realloc()、 [CX] reallocarray() 或 POSIX.1-2024 中按 malloc() 的方式分配内存的函数返回的指针不匹配， 或者该空间已通过调用 free()、[CX] reallocarray()、 或 realloc() 被释放， 则行为未定义。

若 size 非零且未分配新对象的内存，则不应释放旧对象。

对 realloc() [CX] 或 reallocarray() 的连续调用所分配的存储的顺序和连续性未指定。若分配成功，返回的指针应适当对齐，使其可以赋给具有基础对齐要求的任何类型对象的指针，并用于访问所分配空间中此类对象（直到该空间被显式释放或重新分配）。每次此类分配应产生一个与其他任何对象不相交的对象的指针。返回的指针应指向所分配空间的起始位置（最低字节地址）。若无法分配空间，应返回空指针。

为确定数据竞争是否存在，realloc() [CX] 和 reallocarray() 应各自表现得如同只访问了通过其参数可访问的内存位置，而不访问其他静态存储期存储。但该函数可以明显地修改其分配的存储。分配或释放特定内存区域的 aligned_alloc()、calloc()、free()、malloc()、[ADV] posix_memalign()、 [CX] reallocarray()、 以及 realloc() 调用应按单一全序发生（参见 4.15.1 内存排序），并且每次此类释放调用应与此顺序中的下一次分配（若有）同步。

返回值 (RETURN VALUE)

成功完成时，realloc() [CX] 和 reallocarray() 应返回指向新对象的指针（其值可以与指向旧对象的指针相同），若未分配新对象，则返回空指针。

[OB] 若 size 为 0， [OB CX] 或 nelem 或 elsize 中任一为 0， [OB] 则以下任一情况发生：

  • [OB] 应返回空指针 [OB CX] 并且，若 ptr 不是空指针，则应将 errno 设置为 [EINVAL]。

  • [OB] 应返回指向所分配空间的指针，并且应释放 ptr 所指向的内存对象。应用程序应确保不使用该指针访问对象。

若可用内存不足，realloc() [CX] 和 reallocarray() 应返回空指针 [CX] 并将 errno 设置为 [ENOMEM]。

错误 (ERRORS)

realloc() [CX] 和 reallocarray() 函数在以下情况下应失败：

[ENOMEM]
[CX] 可用内存不足。

[CX] reallocarray() 函数在以下情况下应失败：

[ENOMEM]
计算 nelem * elsize 会溢出。

realloc() [CX] 和 reallocarray() 函数在以下情况下可以失败：

[EINVAL]
[CX] 所请求的分配大小为 0 且实现不支持 0 大小的分配。
The following sections are informative.

示例 (EXAMPLES)

无。

应用程序使用 (APPLICATION USAGE)

ISO C 标准规定，调用 realloc(p, 0) 时，若因未分配新对象的内存而返回空指针，则是否释放 p 所指向的空间是实现定义的。POSIX.1 则要求：若返回空指针且空间未被释放，实现应设置 errno；仅当 errno 被更改时，POSIX 应用程序才应释放该空间。

原理 (RATIONALE)

参见 malloc() 的 RATIONALE。

未来方向 (FUTURE DIRECTIONS)

ISO C 标准指出，以等于零的 size 参数调用 realloc() 是一项过时特性。此特性可能会在本标准的未来版本中被移除。
