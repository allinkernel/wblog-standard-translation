XSH 函数：listen()

名称 (NAME)

listen — 侦听套接字连接并限制传入连接的队列 (listen — listen for socket connections and limit the queue of incoming connections)

摘要 (SYNOPSIS)

#include <sys/socket.h>

int listen(int socket, int backlog);

说明 (DESCRIPTION)

listen() 函数应将由 socket 参数指定的连接模式套接字标记为接受连接。

backlog 参数向实现提供一个提示，实现应使用该提示来限制套接字侦听队列中未完成连接的数量。实现可以对 backlog 施加限制并静默地减小指定值。通常，较大的 backlog 参数值应导致侦听队列的长度更大或相等。实现应支持最大为 SOMAXCONN（在 <sys/socket.h> 中定义）的 backlog 值。

实现可以在其侦听队列中包含未完成的连接。对已排队的未完成连接和已完成连接数量的限制可以不同。

实现可以设置侦听队列长度的上限——无论是全局的还是每个接受连接的套接字的。如果 backlog 超过此限制，则侦听队列的长度设置为该限制。

如果以小于 0 的 backlog 参数值调用 listen()，该函数的行为就像是以 0 的 backlog 参数值调用的一样。

0 的 backlog 参数可以允许套接字接受连接，在这种情况下，侦听队列的长度可以设置为实现定义的最小值。

所使用的套接字可能要求进程拥有适当的权限才能使用 listen() 函数。

返回值 (RETURN VALUE)

成功完成后，listen() 应返回 0；否则，应返回 -1，并设置 errno 以指示错误。

错误 (ERRORS)

在以下情况下，listen() 函数应失败：

[EBADF]
socket 参数不是有效的文件描述符。
[EDESTADDRREQ]
套接字未绑定到本地地址，且协议不支持在未绑定的套接字上侦听。
[EINVAL]
socket 已连接。
[ENOTSOCK]
socket 参数不引用套接字。
[EOPNOTSUPP]
套接字协议不支持 listen()。

在以下情况下，listen() 函数可以失败：

[EACCES]
调用进程没有适当的权限。
[EINVAL]
socket 已被关闭。
[ENOBUFS]
系统中可用于完成调用的资源不足。
