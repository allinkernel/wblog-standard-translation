XSH 函数：raise()

名称 (NAME)

raise — 向正在执行的进程发送信号

概要 (SYNOPSIS)

#include <signal.h>

int raise(int sig);

说明 (DESCRIPTION)

[CX] The functionality described on this reference page is aligned with the ISO C standard. Any conflict between the requirements described here and the ISO C standard is unintentional. This volume of POSIX.1-2024 defers to the ISO C standard.

raise() 函数应向正在执行的 [CX] 线程或进程发送信号 sig。 如果调用了信号处理程序，则 raise() 函数在信号处理程序返回之前不应返回。

[CX] raise() 函数的效果应等同于调用：

pthread_kill(pthread_self(), sig);

返回值 (RETURN VALUE)

成功完成后，应返回 0。否则，应返回非零值 [CX] 并设置 errno 以指示错误。

错误 (ERRORS)

在以下情况下，raise() 函数应失败：

[EINVAL]
[CX] sig 参数的值是无效的信号编号。
