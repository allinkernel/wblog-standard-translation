XSH 函数：fread()

[h4_00001] 名称 (NAME)

[blockquote_00002] fread — 二进制输入 (binary input)

[h4_00003] 提要 (SYNOPSIS)

[p_00004] #include <stdio.h>

size_t fread(void *restrict ptr, size_t size, size_t nitems,
FILE *restrict stream);

[h4_00005] 说明 (DESCRIPTION)

[CX] The functionality described on this reference page is aligned with the ISO C standard. Any conflict between the requirements described here and the ISO C standard is unintentional. This volume of POSIX.1-2024 defers to the ISO C standard.

[p_00006] fread() 函数应从 stream 指向的流中读取至多 nitems 个元素到 ptr 指向的数组中，这些元素的大小以字节为单位由 size 指定。对于每个对象，应调用 fgetc() 函数 size 次，并将结果按读取顺序存储在恰好覆盖该对象的 unsigned char 数组中。流的文件位置指示符（如果已定义）应按成功读取的字节数前进。如果发生错误，则流的文件位置指示符的结果值未指定。如果读取了部分元素，则其值未指定。

[p_00007] [CX] fread() 函数可以标记更新与 stream 关联的文件的上次数据访问时间戳。当使用 stream 的 fgetc()、fgets()、fread()、fscanf()、getc()、getchar()、getdelim()、getline() 或 scanf() 首次成功执行并返回了不是由先前对 ungetc() 的调用提供的数据时，上次数据访问时间戳应被标记更新。

[h4_00008] 返回值 (RETURN VALUE)

[p_00009] fread() 函数应返回成功读取的元素数，只有在遇到错误或文件末尾，或 size 为零时，该数才应小于 nitems。如果 size 或 nitems 为 0，则 fread() 应返回 0，并且数组的内容和流的状态应保持不变。否则，如果发生错误，应设置流的错误指示符，[CX] 并应设置 errno 以指示错误。

[h4_00010] 错误 (ERRORS)

[p_00011] 参见 fgetc()。

The following sections are informative.

[h4_00012] 示例 (EXAMPLES)

[h5_00013] 从流中读取 (Reading from a Stream)

[p_00014] 以下示例将单个 100 字节定长记录从 fp 流传送到 buf 指向的数组中。

#include <stdio.h>
...
size_t elements_read;
char buf[100];
FILE *fp;
...
elements_read = fread(buf, sizeof(buf), 1, fp);
...

[p_00015] 如果发生读取错误，elements_read 将为零，但从流中读取的字节数可以是零到 sizeof(buf)-1 之间的任何值。

[p_00016] 以下示例从 fp 流中读取多个单字节元素到 buf 指向的数组中。

#include <stdio.h>
...
size_t bytes_read;
char buf[100];
FILE *fp;
...
bytes_read = fread(buf, 1, sizeof(buf), fp);
...

[p_00017] 如果发生读取错误，bytes_read 将包含从流中读取的字节数。

[h4_00018] 应用程序用法 (APPLICATION USAGE)

[p_00019] 必须使用 ferror() 或 feof() 函数来区分错误条件和文件末尾条件。

[p_00020] 由于元素长度和字节顺序可能存在差异，使用 fwrite() 写入的文件是应用程序相关的，并且可能无法由不同的应用程序或在不同的处理器上运行的同一应用程序使用 fread() 读取。
