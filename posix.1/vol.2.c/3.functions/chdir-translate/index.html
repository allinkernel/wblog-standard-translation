XSH 函数：chdir()

名称 (NAME)

chdir — 更改工作目录

提要 (SYNOPSIS)

#include <unistd.h>

int chdir(const char *path);

说明 (DESCRIPTION)

chdir() 函数应使由 path 参数所指向的路径名命名的目录成为当前工作目录；即，不以 '/' 开头的路径名的路径搜索的起始点。

返回值 (RETURN VALUE)

成功完成后，应返回 0。否则，应返回 -1，当前工作目录应保持不变，并且应设置 errno 以指示错误。

错误 (ERRORS)

在以下情况下，chdir() 函数应失败：

[EACCES]
路径名的任何组件被拒绝搜索权限。
[ELOOP]
在解析 path 参数期间遇到的符号链接中存在循环。
[ENAMETOOLONG]
路径名的某个组件的长度长于 {NAME_MAX}。
[ENOENT]
path 的某个组件没有命名一个现有目录，或者 path 是空字符串。
[ENOTDIR]
路径名的某个组件命名了一个既不是目录也不是指向目录的符号链接的现有文件。

在以下情况下，chdir() 函数可以失败：

[ELOOP]
在解析 path 参数期间遇到的符号链接超过 {SYMLOOP_MAX} 个。
[ENAMETOOLONG]
路径名的长度超过 {PATH_MAX}，或者符号链接的路径名解析产生的中间结果的长度超过 {PATH_MAX}。
The following sections are informative.

示例 (EXAMPLES)

更改当前工作目录 (Changing the Current Working Directory)

以下示例使 directory 所指向的值 /tmp 成为当前工作目录。

#include <unistd.h>
...
char *directory = "/tmp";
int ret;
 
ret = chdir (directory);

应用程序使用 (APPLICATION USAGE)

无。

原理 (RATIONALE)

chdir() 函数只影响当前进程的工作目录。

未来方向 (FUTURE DIRECTIONS)

无。
