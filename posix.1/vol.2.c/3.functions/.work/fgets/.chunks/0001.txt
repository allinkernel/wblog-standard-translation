[h4_00001] [A1][/A1]NAME
[blockquote_00002] fgets — get a string from a stream
[h4_00003] [A2][/A2]SYNOPSIS
[p_00004] [CODE3]
[h4_00005] [A4][/A4]DESCRIPTION
[p_00006] The [I5]fgets[/I5]() function shall read bytes from [I6]stream[/I6] into the array pointed to by [I7]s[/I7] until [I8]n[/I8]-1 bytes are read, or a &lt;newline&gt; is read and transferred to [I9]s[/I9], or an end-of-file condition is encountered. A null byte shall be written immediately after the last byte read into the array. If the end-of-file condition is encountered before any bytes are read, the contents of the array pointed to by [I10]s[/I10] shall not be changed.
[p_00007] [S11][[A12]CX[/A12]][/S11] [IMG13] The [I14]fgets[/I14]() function may mark the last data access timestamp of the file associated with [I15]stream[/I15] for update. The last data access timestamp shall be marked for update by the first successful execution of [A16][I17]fgetc[/I17]()[/A16], [I18]fgets[/I18](), [A19][I20]fread[/I20]()[/A19], [A21][I22]fscanf[/I22]()[/A21], [A23][I24]getc[/I24]()[/A23], [A25][I26]getchar[/I26]()[/A25], [A27][I28]getdelim[/I28]()[/A27], [A29][I30]getline[/I30]()[/A29], or [A31][I32]scanf[/I32]()[/A31] using [I33]stream[/I33] that returns data not supplied by a prior call to [A34][I35]ungetc[/I35]()[/A34]. [IMG36]
[h4_00008] [A37][/A37]RETURN VALUE
[p_00009] Upon successful completion, [I38]fgets[/I38]() shall return [I39]s[/I39]. If the stream is at end-of-file, the end-of-file indicator for the stream shall be set and [I40]fgets[/I40]() shall return a null pointer. If an error occurs, the error indicator for the stream shall be set, [I41]fgets[/I41]() shall return a null pointer, [S42][[A43]CX[/A43]][/S42] [IMG44] &nbsp;and shall set [I45]errno[/I45] to indicate the error. [IMG46]
[h4_00010] [A47][/A47]ERRORS
[p_00011] Refer to [A48][I49]fgetc[/I49]()[/A48].
[h4_00012] [A50][/A50]EXAMPLES
[h5_00013] [A51][/A51]Reading Input
[p_00014] The following example uses [I52]fgets[/I52]() to read lines of input. It assumes that the file it is reading is a text file and that lines in this text file are no longer than 16384 (or {LINE_MAX} if it is less than 16384 on the implementation where it is running) bytes long. (Note that the standard utilities have no line length limit if [I53]sysconf[/I53](_SC_LINE_MAX) returns -1 without setting [I54]errno[/I54]. This example assumes that [I55]sysconf[/I55](_SC_LINE_MAX) will not fail.)
