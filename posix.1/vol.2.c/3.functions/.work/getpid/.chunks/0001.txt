[h4_00001] [A1][/A1]NAME
[blockquote_00002] getpid — get the process ID
[h4_00003] [A2][/A2]SYNOPSIS
[p_00004] [CODE3]
[h4_00005] [A4][/A4]DESCRIPTION
[p_00006] The [I5]getpid[/I5]() function shall return the process ID of the calling process.
[h4_00007] [A6][/A6]RETURN VALUE
[p_00008] The [I7]getpid[/I7]() function shall always be successful and no return value is reserved to indicate an error.
[h4_00009] [A8][/A8]ERRORS
[p_00010] No errors are defined.
