[h4_00001] [A1][/A1]NAME
[blockquote_00002] send — send a message on a socket
[h4_00003] [A2][/A2]SYNOPSIS
[p_00004] [CODE3]
[h4_00005] [A4][/A4]DESCRIPTION
[p_00006] The [I5]send[/I5]() function shall initiate transmission of a message from the specified socket to its peer. The [I6]send[/I6]() function shall send a message only when the socket is connected. If the socket is a connectionless-mode socket, the message shall be sent to the pre-specified peer address.
[p_00007] The [I7]send[/I7]() function takes the following arguments:
[dt_00008] [I8]socket[/I8]
[dd_00009] Specifies the socket file descriptor.
[dt_00010] [I9]buffer[/I9]
[dd_00011] Points to the buffer containing the message to send.
[dt_00012] [I10]length[/I10]
[dd_00013] Specifies the length of the message in bytes.
[dt_00014] [I11]flags[/I11]
[dd_00015] Specifies the type of message transmission. Values of this argument are formed by logically OR'ing zero or more of the following flags:   MSG_EOR Terminates a record (if supported by the protocol). MSG_OOB Sends out-of-band data on sockets that support out-of-band communications. The significance and semantics of out-of-band data are protocol-specific. MSG_NOSIGNAL Requests not to send the SIGPIPE signal if an attempt to send is made on a stream-oriented socket that is no longer connected. The [EPIPE] error shall still be returned.
[p_00016] The length of the message to be sent is specified by the [I12]length[/I12] argument. If the message is too long to pass through the underlying protocol, [I13]send[/I13]() shall fail and no data shall be transmitted.
[p_00017] Successful completion of a call to [I14]send[/I14]() does not guarantee delivery of the message. A return value of -1 indicates only locally-detected errors.
[p_00018] If space is not available at the sending socket to hold the message to be transmitted, and the socket file descriptor does not have O_NONBLOCK set, [I15]send[/I15]() shall block until space is available or a timeout occurs (see SO_SNDTIMEO in [A16][I17]2.10.16 Use of Options[/I17][/A16]). If space is not available at the sending socket to hold the message to be transmitted, and the socket file descriptor does have O_NONBLOCK set, [I18]send[/I18]() shall fail. The [A19][I20]select[/I20]()[/A19] and [A21][I22]poll[/I22]()[/A21] functions can be used to determine when it is possible to send more data.
[p_00019] The socket in use may require the process to have appropriate privileges to use the [I23]send[/I23]() function.
[h4_00020] [A24][/A24]RETURN VALUE
[p_00021] Upon successful completion, [I25]send[/I25]() shall return the number of bytes sent. Otherwise, -1 shall be returned and [I26]errno[/I26] set to indicate the error.
[h4_00022] [A27][/A27]ERRORS
[p_00023] The [I28]send[/I28]() function shall fail if:
[dt_00024] [EAGAIN] or [EWOULDBLOCK]
[dd_00025] The socket's file descriptor is marked O_NONBLOCK and the requested operation would block. See also SO_SNDTIMEO in [A29][I30]2.10.16 Use of Options[/I30][/A29].
[dt_00026] [EBADF]
[dd_00027] The [I31]socket[/I31] argument is not a valid file descriptor.
[dt_00028] [ECONNRESET]
[dd_00029] A connection was forcibly closed by a peer.
[dt_00030] [EDESTADDRREQ]
[dd_00031] The socket is not connection-mode and no peer address is set.
[dt_00032] [EINTR]
[dd_00033] A signal interrupted [I32]send[/I32]() before any data was transmitted.
[dt_00034] [EMSGSIZE]
[dd_00035] The message is too large to be sent all at once, as the socket requires.
[dt_00036] [ENOTCONN]
[dd_00037] The socket is not connected.
[dt_00038] [ENOTSOCK]
[dd_00039] The [I33]socket[/I33] argument does not refer to a socket.
[dt_00040] [EOPNOTSUPP]
[dd_00041] The [I34]socket[/I34] argument is associated with a socket that does not support one or more of the values set in [I35]flags[/I35].
[dt_00042] [EPIPE]
[dd_00043] The socket is shut down for writing, or the socket is connection-mode and is no longer connected. In the latter case, and if the socket is of type SOCK_STREAM or SOCK_SEQPACKET and the MSG_NOSIGNAL flag is not set, the SIGPIPE signal is generated to the calling thread.
[p_00044] The [I36]send[/I36]() function may fail if:
[dt_00045] [EACCES]
[dd_00046] The calling process does not have appropriate privileges.
[dt_00047] [EIO]
[dd_00048] An I/O error occurred while reading from or writing to the file system.
[dt_00049] [ENETDOWN]
[dd_00050] The local network interface used to reach the destination is down.
[dt_00051] [ENETUNREACH]
[dd_00052] No route to the network is present.
[dt_00053] [ENOBUFS]
[dd_00054] Insufficient resources were available in the system to perform the operation.
[h4_00055] [A37][/A37]EXAMPLES
[p_00056] None.
[h4_00057] [A38][/A38]APPLICATION USAGE
[p_00058] If the [I39]socket[/I39] argument refers to a connection-mode socket, the [I40]send[/I40]() function is equivalent to [A41][I42]sendto[/I42]()[/A41] (with any value for the [I43]dest_addr[/I43] and [I44]dest_len[/I44] arguments, as they are ignored in this case). If the [I45]socket[/I45] argument refers to a socket and the [I46]flags[/I46] argument is 0, the [I47]send[/I47]() function is equivalent to [A48][I49]write[/I49]()[/A48].
