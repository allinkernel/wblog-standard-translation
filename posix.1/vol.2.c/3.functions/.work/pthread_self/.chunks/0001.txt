[h4_00001] [A1][/A1]NAME
[blockquote_00002] pthread_self — get the calling thread ID
[h4_00003] [A2][/A2]SYNOPSIS
[p_00004] [CODE3]
[h4_00005] [A4][/A4]DESCRIPTION
[p_00006] The [I5]pthread_self[/I5]() function shall return the thread ID of the calling thread.
[h4_00007] [A6][/A6]RETURN VALUE
[p_00008] The [I7]pthread_self[/I7]() function shall always be successful and no return value is reserved to indicate an error.
[h4_00009] [A8][/A8]ERRORS
[p_00010] No errors are defined.
[h4_00011] [A9][/A9]EXAMPLES
[p_00012] None.
[h4_00013] [A10][/A10]APPLICATION USAGE
[p_00014] None.
[h4_00015] [A11][/A11]RATIONALE
[p_00016] The [I12]pthread_self[/I12]() function provides a capability similar to the [A13][I14]getpid[/I14]()[/A13] function for processes and the rationale is the same: the creation call does not provide the thread ID to the created thread.
