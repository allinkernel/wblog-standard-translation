[h4_00001] [A1][/A1]NAME
[blockquote_00002] strtol, strtoll — convert a string to a long integer
[h4_00003] [A2][/A2]SYNOPSIS
[p_00004] [CODE3]
[h4_00005] [A4][/A4]DESCRIPTION
[p_00006] These functions shall convert the initial portion of the string pointed to by [I5]nptr[/I5] to a type [B6]long[/B6] and [B7]long long[/B7] representation, respectively. First, they decompose the input string into three parts:
[p_00007] An initial, possibly empty, sequence of white-space bytes
[p_00008] A subject sequence interpreted as an integer represented in some radix determined by the value of [I8]base[/I8]
[p_00009] A final string of one or more unrecognized characters, including the terminating NUL character of the input string.
[p_00010] Then they shall attempt to convert the subject sequence to an integer, and return the result.
[p_00011] If the value of [I9]base[/I9] is 0, the expected form of the subject sequence is that of a decimal constant, octal constant, or hexadecimal constant, any of which may be preceded by a [CODE10] or [CODE11] sign. A decimal constant begins with a non-zero digit, and consists of a sequence of decimal digits. An octal constant consists of the prefix [CODE12] optionally followed by a sequence of the digits [CODE13] to [CODE14] only. A hexadecimal constant consists of the prefix 0x or 0X followed by a sequence of the decimal digits and letters [CODE15] (or [CODE16]) to [CODE17] (or [CODE18]) with values 10 to 15 respectively.
[p_00012] If the value of [I19]base[/I19] is between 2 and 36, the expected form of the subject sequence is a sequence of letters and digits representing an integer with the radix specified by [I20]base[/I20], optionally preceded by a [CODE21] or [CODE22] sign. The letters from [CODE23] (or [CODE24]) to [CODE25] (or [CODE26]) inclusive are ascribed the values 10 to 35; only letters whose ascribed values are less than that of [I27]base[/I27] are permitted. If the value of [I28]base[/I28] is 16, the characters 0x or 0X may optionally precede the sequence of letters and digits, following the sign if present.
[p_00013] The subject sequence is defined as the longest initial subsequence of the input string, starting with the first non-white-space byte, that is of the expected form. The subject sequence shall contain no characters if the input string is empty or consists entirely of white-space bytes, or if the first non-white-space byte is other than a sign or a permissible letter or digit.
[p_00014] If the subject sequence has the expected form and the value of [I29]base[/I29] is 0, the sequence of characters starting with the first digit shall be interpreted as an integer constant. If the subject sequence has the expected form and the value of [I30]base[/I30] is between 2 and 36, it shall be used as the base for conversion, ascribing to each letter its value as given above. If the subject sequence begins with a &lt;hyphen-minus&gt;, the resulting value shall be the negative of the converted value. A pointer to the final string shall be stored in the object pointed to by [I31]endptr[/I31], provided that [I32]endptr[/I32] is not a null pointer.
[p_00015] In other than the C [S33][[A34]CX[/A34]][/S33] [IMG35] &nbsp;or POSIX [IMG36] locale, additional locale-specific subject sequence forms may be accepted.
[p_00016] If the subject sequence is empty or does not have the expected form, no conversion is performed; the value of [I37]nptr[/I37] shall be stored in the object pointed to by [I38]endptr[/I38], provided that [I39]endptr[/I39] is not a null pointer.
[p_00017] These functions shall not change the setting of [I40]errno[/I40] if successful.
[p_00018] Since 0, {LONG_MIN} or {LLONG_MIN}, and {LONG_MAX} or {LLONG_MAX} are returned on error and are also valid returns on success, an application wishing to check for error situations should set [I41]errno[/I41] to 0, then call [I42]strtol[/I42]() or [I43]strtoll[/I43](), then check [I44]errno[/I44].
[h4_00019] [A45][/A45]RETURN VALUE
[p_00020] Upon successful completion, these functions shall return the converted value, if any. If no conversion could be performed, 0 shall be returned [S46][[A47]CX[/A47]][/S46] [IMG48] &nbsp;and [I49]errno[/I49] may be set to [EINVAL]. [IMG50]
[p_00021] [S51][[A52]CX[/A52]][/S51] [IMG53] If the value of [I54]base[/I54] is not supported, 0 shall be returned and [I55]errno[/I55] shall be set to [EINVAL]. [IMG56]
[p_00022] If the correct value is outside the range of representable values, {LONG_MIN}, {LONG_MAX}, {LLONG_MIN}, or {LLONG_MAX} shall be returned (according to the sign of the value), and [I57]errno[/I57] set to [ERANGE].
[h4_00023] [A58][/A58]ERRORS
[p_00024] These functions shall fail if:
[dt_00025] [EINVAL]
[dd_00026] [S59][[A60]CX[/A60]][/S59] [IMG61] The value of [I62]base[/I62] is not supported. [IMG63]
[dt_00027] [ERANGE]
[dd_00028] The value to be returned is not representable.
[p_00029] These functions may fail if:
[dt_00030] [EINVAL]
[dd_00031] No conversion could be performed.
[h4_00032] [A64][/A64]EXAMPLES
[p_00033] None.
[h4_00034] [A65][/A65]APPLICATION USAGE
[p_00035] Since the value of [I66]*endptr[/I66] is unspecified if the value of [I67]base[/I67] is not supported, applications should either ensure that [I68]base[/I68] has a supported value (0 or between 2 and 36) before the call, or check for an [EINVAL] error before examining [I69]*endptr[/I69].
