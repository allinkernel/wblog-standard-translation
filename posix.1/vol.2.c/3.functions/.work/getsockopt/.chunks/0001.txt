[h4_00001] [A1][/A1]NAME
[blockquote_00002] getsockopt — get the socket options
[h4_00003] [A2][/A2]SYNOPSIS
[p_00004] [CODE3]
[h4_00005] [A4][/A4]DESCRIPTION
[p_00006] The [I5]getsockopt[/I5]() function manipulates options associated with a socket.
[p_00007] The [I6]getsockopt[/I6]() function shall retrieve the value for the option specified by the [I7]option_name[/I7] argument for the socket specified by the [I8]socket[/I8] argument. If the size of the option value is greater than [I9]option_len[/I9], the value stored in the object pointed to by the [I10]option_value[/I10] argument shall be silently truncated. Otherwise, the object pointed to by the [I11]option_len[/I11] argument shall be modified to indicate the actual length of the value.
[p_00008] The [I12]level[/I12] argument specifies the protocol level at which the option resides. To retrieve options at the socket level, specify the [I13]level[/I13] argument as SOL_SOCKET. To retrieve options at other levels, supply the appropriate level identifier for the protocol controlling the option. For example, to indicate that an option is interpreted by the TCP (Transmission Control Protocol), set [I14]level[/I14] to IPPROTO_TCP as defined in the [A15][I16]&lt;netinet/in.h&gt;[/I16][/A15] header.
[p_00009] The socket in use may require the process to have appropriate privileges to use the [I17]getsockopt[/I17]() function.
[p_00010] The [I18]option_name[/I18] argument specifies a single option to be retrieved. It can be one of the socket-level options defined in [A19][I20]&lt;sys/socket.h&gt;[/I20][/A19] and described in [A21][I22]2.10.16 Use of Options[/I22][/A21].
[h4_00011] [A23][/A23]RETURN VALUE
[p_00012] Upon successful completion, [I24]getsockopt[/I24]() shall return 0; otherwise, -1 shall be returned and [I25]errno[/I25] set to indicate the error.
[h4_00013] [A26][/A26]ERRORS
[p_00014] The [I27]getsockopt[/I27]() function shall fail if:
[dt_00015] [EBADF]
[dd_00016] The [I28]socket[/I28] argument is not a valid file descriptor.
[dt_00017] [EINVAL]
[dd_00018] The specified option is invalid at the specified socket level.
[dt_00019] [ENOPROTOOPT]
[dd_00020] The option is not supported by the protocol.
[dt_00021] [ENOTSOCK]
[dd_00022] The [I29]socket[/I29] argument does not refer to a socket.
[p_00023] The [I30]getsockopt[/I30]() function may fail if:
[dt_00024] [EACCES]
[dd_00025] The calling process does not have appropriate privileges.
[dt_00026] [EINVAL]
[dd_00027] The socket has been shut down.
[dt_00028] [ENOBUFS]
[dd_00029] Insufficient resources are available in the system to complete the function.
