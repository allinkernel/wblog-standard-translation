[h4_00001] [A1][/A1]NAME
[blockquote_00002] connect — connect a socket
[h4_00003] [A2][/A2]SYNOPSIS
[p_00004] [CODE3]
[h4_00005] [A4][/A4]DESCRIPTION
[p_00006] The [I5]connect[/I5]() function shall attempt to make a connection on a connection-mode socket or to set or reset the peer address of a connectionless-mode socket. The function takes the following arguments:
[dt_00007] [I6]socket[/I6]
[dd_00008] Specifies the file descriptor associated with the socket.
[dt_00009] [I7]address[/I7]
[dd_00010] Points to a [B8]sockaddr[/B8] structure containing the peer address. The length and format of the address depend on the address family of the socket.
[dt_00011] [I9]address_len[/I9]
[dd_00012] Specifies the length of the [B10]sockaddr[/B10] structure pointed to by the [I11]address[/I11] argument.
[p_00013] If the address family of the socket is AF_UNIX, the application shall ensure that a null terminator after the pathname is included in the [I12]sun_path[/I12] member of [I13]address[/I13] as a [B14]sockaddr_un[/B14] structure, and that [I15]address_len[/I15] is at least [CODE16] plus the length of the pathname.
[p_00014] If the socket has not already been bound to a local address, [I17]connect[/I17]() shall bind it to an address which, unless the socket's address family is AF_UNIX, is an unused local address.
[p_00015] If the initiating socket is not connection-mode, then [I18]connect[/I18]() shall set the socket's peer address, and no connection is made. For SOCK_DGRAM sockets, the peer address identifies where all datagrams are sent on subsequent [A19][I20]send[/I20]()[/A19] functions, and limits the remote sender for subsequent [A21][I22]recv[/I22]()[/A21] functions. If the [I23]sa_family[/I23] member of [I24]address[/I24] is AF_UNSPEC, the socket's peer address shall be reset. Note that despite no connection being made, the term &quot;connected&quot; is used to describe a connectionless-mode socket for which a peer address has been set.
[p_00016] If the initiating socket is connection-mode, then [I25]connect[/I25]() shall attempt to establish a connection to the address specified by the [I26]address[/I26] argument. If the connection cannot be established immediately and O_NONBLOCK is not set for the file descriptor for the socket, [I27]connect[/I27]() shall block for up to an unspecified timeout interval until the connection is established. If the timeout interval expires before the connection is established, [I28]connect[/I28]() shall fail and the connection attempt shall be aborted. If [I29]connect[/I29]() is interrupted by a signal that is caught while blocked waiting to establish a connection, [I30]connect[/I30]() shall fail and set [I31]errno[/I31] to [EINTR], but the connection request shall not be aborted, and the connection shall be established asynchronously.
[p_00017] If the connection cannot be established immediately and O_NONBLOCK is set for the file descriptor for the socket, [I32]connect[/I32]() shall fail and set [I33]errno[/I33] to [EINPROGRESS], but the connection request shall not be aborted, and the connection shall be established asynchronously. Subsequent calls to [I34]connect[/I34]() for the same socket, before the connection is established, shall fail and set [I35]errno[/I35] to [EALREADY].
[p_00018] When the connection has been established asynchronously, [A36][I37]pselect[/I37]()[/A36], [A38][I39]select[/I39]()[/A38], [A40][I41]poll[/I41]()[/A40], and [A42][I43]ppoll[/I43]()[/A42] shall indicate that the file descriptor for the socket is ready for writing.
[p_00019] The socket in use may require the process to have appropriate privileges to use the [I44]connect[/I44]() function.
[h4_00020] [A45][/A45]RETURN VALUE
[p_00021] Upon successful completion, [I46]connect[/I46]() shall return 0; otherwise, -1 shall be returned and [I47]errno[/I47] set to indicate the error.
[h4_00022] [A48][/A48]ERRORS
[p_00023] The [I49]connect[/I49]() function shall fail if:
[dt_00024] [EADDRNOTAVAIL]
[dd_00025] The specified address is not available from the local machine.
[dt_00026] [EAFNOSUPPORT]
[dd_00027] The specified address is not a valid address for the address family of the specified socket.
[dt_00028] [EALREADY]
[dd_00029] A connection request is already in progress for the specified socket.
[dt_00030] [EBADF]
[dd_00031] The [I50]socket[/I50] argument is not a valid file descriptor.
[dt_00032] [ECONNREFUSED]
[dd_00033] The target address was not listening for connections or refused the connection request.
[dt_00034] [EINPROGRESS]
[dd_00035] O_NONBLOCK is set for the file descriptor for the socket and the connection cannot be immediately established; the connection shall be established asynchronously.
[dt_00036] [EINTR]
[dd_00037] The attempt to establish a connection was interrupted by delivery of a signal that was caught; the connection shall be established asynchronously.
[dt_00038] [EISCONN]
[dd_00039] The specified socket is connection-mode and is already connected.
[dt_00040] [ENETUNREACH]
[dd_00041] No route to the network is present.
[dt_00042] [ENOTSOCK]
[dd_00043] The [I51]socket[/I51] argument does not refer to a socket.
[dt_00044] [EPROTOTYPE]
[dd_00045] The specified address has a different type than the socket bound to the specified peer address.
[dt_00046] [ETIMEDOUT]
[dd_00047] The attempt to connect timed out before a connection was made.
[p_00048] If the address family of the socket is AF_UNIX, then [I52]connect[/I52]() shall fail if:
[dt_00049] [EIO]
[dd_00050] An I/O error occurred while reading from or writing to the file system.
[dt_00051] [ELOOP]
[dd_00052] A loop exists in symbolic links encountered during resolution of the pathname in [I53]address[/I53].
[dt_00053] [ENAMETOOLONG]
[dd_00054] The length of a component of a pathname is longer than {NAME_MAX}.
[dt_00055] [ENOENT]
[dd_00056] A component of the pathname does not name an existing file or the pathname is an empty string.
[dt_00057] [ENOTDIR]
[dd_00058] A component of the path prefix of the pathname in [I54]address[/I54] names an existing file that is neither a directory nor a symbolic link to a directory, or the pathname in [I55]address[/I55] contains at least one non-&lt;slash&gt; character and ends with one or more trailing &lt;slash&gt; characters and the last pathname component names an existing file that is neither a directory nor a symbolic link to a directory.
[p_00059] The [I56]connect[/I56]() function may fail if:
[dt_00060] [EACCES]
[dd_00061] Search permission is denied for a component of the path prefix; or write access to the named socket is denied.
[dt_00062] [EADDRINUSE]
[dd_00063] Attempt to establish a connection that uses addresses that are already in use.
[dt_00064] [ECONNRESET]
[dd_00065] Remote host reset the connection request.
[dt_00066] [EHOSTUNREACH]
[dd_00067] The destination host cannot be reached (probably because the host is down or a remote router cannot reach it).
[dt_00068] [EINVAL]
[dd_00069] The [I57]address_len[/I57] argument is not a valid length for the address family; or invalid address family in the [B58]sockaddr[/B58] structure.
[dt_00070] [ELOOP]
[dd_00071] More than {SYMLOOP_MAX} symbolic links were encountered during resolution of the pathname in [I59]address[/I59].
[dt_00072] [ENAMETOOLONG]
[dd_00073] The length of a pathname exceeds {PATH_MAX}, or pathname resolution of a symbolic link produced an intermediate result with a length that exceeds {PATH_MAX}.
[dt_00074] [ENETDOWN]
[dd_00075] The local network interface used to reach the destination is down.
[dt_00076] [ENOBUFS]
[dd_00077] No buffer space is available.
[dt_00078] [EOPNOTSUPP]
[dd_00079] The socket is listening and cannot be connected.
[h4_00080] [A60][/A60]EXAMPLES
[p_00081] None.
[h4_00082] [A61][/A61]APPLICATION USAGE
[p_00083] If [I62]connect[/I62]() fails, the state of the socket is unspecified. Conforming applications should close the file descriptor and create a new socket before attempting to reconnect.
[p_00084] For AF_UNIX sockets, some implementations support an extension where [I63]address_len[/I63] does not have to include a null terminator for the pathname stored in [I64]sun_path[/I64], which in turn allows a pathname to be one byte longer. However, such usage is not portable, and carries a risk of accessing beyond the intended bounds of the pathname length.
