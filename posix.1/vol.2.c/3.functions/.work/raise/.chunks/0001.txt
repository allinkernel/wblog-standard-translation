[h4_00001] [A1][/A1]NAME
[blockquote_00002] raise — send a signal to the executing process
[h4_00003] [A2][/A2]SYNOPSIS
[p_00004] [CODE3]
[h4_00005] [A4][/A4]DESCRIPTION
[p_00006] The [I5]raise[/I5]() function shall send the signal [I6]sig[/I6] to the executing [S7][[A8]CX[/A8]][/S7] [IMG9] &nbsp;thread or process. [IMG10] If a signal handler is called, the [I11]raise[/I11]() function shall not return until after the signal handler does.
[p_00007] [S12][[A13]CX[/A13]][/S12] [IMG14] The effect of the [I15]raise[/I15]() function shall be equivalent to calling:
[h4_00008] [A16][/A16]RETURN VALUE
[p_00009] Upon successful completion, 0 shall be returned. Otherwise, a non-zero value shall be returned [S17][[A18]CX[/A18]][/S17] [IMG19] &nbsp;and [I20]errno[/I20] shall be set to indicate the error. [IMG21]
[h4_00010] [A22][/A22]ERRORS
[p_00011] The [I23]raise[/I23]() function shall fail if:
[dt_00012] [EINVAL]
[dd_00013] [S24][[A25]CX[/A25]][/S24] [IMG26] The value of the [I27]sig[/I27] argument is an invalid signal number. [IMG28]

[p_00017] None.
