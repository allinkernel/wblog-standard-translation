[h4_00001] [A1][/A1]NAME
[blockquote_00002] fwrite — binary output
[h4_00003] [A2][/A2]SYNOPSIS
[p_00004] [CODE3]
[h4_00005] [A4][/A4]DESCRIPTION
[p_00006] The [I5]fwrite[/I5]() function shall write, from the array pointed to by [I6]ptr[/I6], up to [I7]nitems[/I7] elements whose size is specified by [I8]size[/I8], to the stream pointed to by [I9]stream[/I9]. For each object, [I10]size[/I10] calls shall be made to the [A11][I12]fputc[/I12]()[/A11] function, taking the values (in order) from an array of [B13]unsigned char[/B13] exactly overlaying the object. The file-position indicator for the stream (if defined) shall be advanced by the number of bytes successfully written. If an error occurs, the resulting value of the file-position indicator for the stream is unspecified.
[p_00007] [S14][[A15]CX[/A15]][/S14] [IMG16] The last data modification and last file status change timestamps of the file shall be marked for update between the successful execution of [I17]fwrite[/I17]() and the next successful completion of a call to [A18][I19]fflush[/I19]()[/A18] or [A20][I21]fclose[/I21]()[/A20] on the same stream, or a call to [A22][I23]exit[/I23]()[/A22] or [A24][I25]abort[/I25]()[/A24]. [IMG26]
[h4_00008] [A27][/A27]RETURN VALUE
[p_00009] The [I28]fwrite[/I28]() function shall return the number of elements successfully written, which shall be less than [I29]nitems[/I29] only if a write error is encountered. If [I30]size[/I30] or [I31]nitems[/I31] is 0, [I32]fwrite[/I32]() shall return 0 and the state of the stream remains unchanged. Otherwise, if a write error occurs, the error indicator for the stream shall be set, [S33][[A34]CX[/A34]][/S33] [IMG35] &nbsp;and [I36]errno[/I36] shall be set to indicate the error. [IMG37]
[h4_00010] [A38][/A38]ERRORS
[p_00011] Refer to [A39][I40]fputc[/I40]()[/A39].
[h4_00012] [A41][/A41]EXAMPLES
[p_00013] None.
[h4_00014] [A42][/A42]APPLICATION USAGE
[p_00015] Because of possible differences in element length and byte ordering, files written using [I43]fwrite[/I43]() are application-dependent, and possibly cannot be read using [A44][I45]fread[/I45]()[/A44] by a different application or by the same application on a different processor.
