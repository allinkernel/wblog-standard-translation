[h4_00001] [A1][/A1]NAME
[blockquote_00002] chdir — change working directory
[h4_00003] [A2][/A2]SYNOPSIS
[p_00004] [CODE3]
[h4_00005] [A4][/A4]DESCRIPTION
[p_00006] The [I5]chdir[/I5]() function shall cause the directory named by the pathname pointed to by the [I6]path[/I6] argument to become the current working directory; that is, the starting point for path searches for pathnames not beginning with [CODE7].
[h4_00007] [A8][/A8]RETURN VALUE
[p_00008] Upon successful completion, 0 shall be returned. Otherwise, -1 shall be returned, the current working directory shall remain unchanged, and [I9]errno[/I9] shall be set to indicate the error.
[h4_00009] [A10][/A10]ERRORS
[p_00010] The [I11]chdir[/I11]() function shall fail if:
[dt_00011] [EACCES]
[dd_00012] Search permission is denied for any component of the pathname.
[dt_00013] [ELOOP]
[dd_00014] A loop exists in symbolic links encountered during resolution of the [I12]path[/I12] argument.
[dt_00015] [ENAMETOOLONG]
[dd_00016] The length of a component of a pathname is longer than {NAME_MAX}.
[dt_00017] [ENOENT]
[dd_00018] A component of [I13]path[/I13] does not name an existing directory or [I14]path[/I14] is an empty string.
[dt_00019] [ENOTDIR]
[dd_00020] A component of the pathname names an existing file that is neither a directory nor a symbolic link to a directory.
[p_00021] The [I15]chdir[/I15]() function may fail if:
[dt_00022] [ELOOP]
[dd_00023] More than {SYMLOOP_MAX} symbolic links were encountered during resolution of the [I16]path[/I16] argument.
[dt_00024] [ENAMETOOLONG]
[dd_00025] The length of a pathname exceeds {PATH_MAX}, or pathname resolution of a symbolic link produced an intermediate result with a length that exceeds {PATH_MAX}.
