[h4_00001] [A1][/A1]NAME
[blockquote_00002] calloc — a memory allocator
[h4_00003] [A2][/A2]SYNOPSIS
[p_00004] [CODE3]
[h4_00005] [A4][/A4]DESCRIPTION
[p_00006] The [I5]calloc[/I5]() function shall allocate unused space for an array of [I6]nelem[/I6] elements each of whose size in bytes is [I7]elsize[/I7]. The space shall be initialized to all bits 0.
[p_00007] The order and contiguity of storage allocated by successive calls to [I8]calloc[/I8]() is unspecified. The pointer returned if the allocation succeeds shall be suitably aligned so that it may be assigned to a pointer to any type of object with a fundamental alignment requirement and then used to access such an object or an array of such objects in the space allocated (until the space is explicitly freed or reallocated). Each such allocation shall yield a pointer to an object disjoint from any other object. The pointer returned shall point to the start (lowest byte address) of the allocated space. If the space cannot be allocated, a null pointer shall be returned. If the size of the space requested is 0, the behavior is implementation-defined: either a null pointer shall be returned, or the behavior shall be as if the size were some non-zero value, except that the behavior is undefined if the returned pointer is used to access an object.
[p_00008] For purposes of determining the existence of a data race, [I9]calloc[/I9]() shall behave as though it accessed only memory locations accessible through its arguments and not other static duration storage. The function may, however, visibly modify the storage that it allocates. Calls to [A10][I11]aligned_alloc[/I11]()[/A10], [I12]calloc[/I12](), [A13][I14]free[/I14]()[/A13], [A15][I16]malloc[/I16]()[/A15], [S17][[A18]ADV[/A18]][/S17] [IMG19] &nbsp;[A20][I21]posix_memalign[/I21]()[/A20], [IMG22]  [S23][[A24]CX[/A24]][/S23] [IMG25] [A26][I27]reallocarray[/I27]()[/A26], [IMG28] &nbsp;and [A29][I30]realloc[/I30]()[/A29] that allocate or deallocate a particular region of memory shall occur in a single total order (see [A31][I32]4.15.1 Memory Ordering[/I32][/A31]), and each such deallocation call shall synchronize with the next allocation (if any) in this order.
[h4_00009] [A33][/A33]RETURN VALUE
[p_00010] Upon successful completion, [I34]calloc[/I34]() shall return a pointer to the allocated space; if either [I35]nelem[/I35] or [I36]elsize[/I36] is 0, the application shall ensure that the pointer is not used to access an object.
[p_00011] Otherwise, it shall return a null pointer [S37][[A38]CX[/A38]][/S37] [IMG39] &nbsp;and set [I40]errno[/I40] to indicate the error. [IMG41]
[h4_00012] [A42][/A42]ERRORS
[p_00013] The [I43]calloc[/I43]() function shall fail if:
[dt_00014] [ENOMEM]
[dd_00015] [S44][[A45]CX[/A45]][/S44] [IMG46] Insufficient memory is available, including the case when [I47]nelem[/I47] [CODE48] [I49]elsize[/I49] would overflow. [IMG50]
[p_00016] The [I51]calloc[/I51]() function may fail if:
[dt_00017] [EINVAL]
[dd_00018] [S52][[A53]CX[/A53]][/S52] [IMG54] [I55]nelem[/I55] or [I56]elsize[/I56] is 0 and the implementation does not support 0 sized allocations. [IMG57]
[h4_00019] [A58][/A58]EXAMPLES
