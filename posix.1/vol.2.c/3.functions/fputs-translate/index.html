XSH 函数：fputs()

[h4_00001] 名称 (NAME)

[blockquote_00002] fputs — 将字符串放到流上 (put a string on a stream)

[h4_00003] 提要 (SYNOPSIS)

[p_00004] #include <stdio.h>

int fputs(const char *restrict s, FILE *restrict stream);

[h4_00005] 说明 (DESCRIPTION)

[CX] The functionality described on this reference page is aligned with the ISO C standard. Any conflict between the requirements described here and the ISO C standard is unintentional. This volume of POSIX.1-2024 defers to the ISO C standard.

[p_00006] fputs() 函数应将 s 指向的以空字符结尾的字符串写入 stream 指向的流。结尾的空字节不应被写入。

[p_00007] [CX] 文件的上次数据修改和上次文件状态更改时间戳应被标记更新，在 fputs() 成功执行与对同一流调用 fflush() 或 fclose() 的下一次成功完成之间，或与调用 exit() 或 abort() 之间。

[h4_00008] 返回值 (RETURN VALUE)

[p_00009] 成功完成后，fputs() 应返回一个非负数。否则，应返回 EOF，设置流的错误指示符，[CX] 并设置 errno 以指示错误。

[h4_00010] 错误 (ERRORS)

[p_00011] 参见 fputc()。

The following sections are informative.

[h4_00012] 示例 (EXAMPLES)

[h5_00013] 打印到标准输出 (Printing to Standard Output)

[p_00014] 以下示例获取当前时间，使用 localtime() 和 asctime() 将其转换为字符串，并使用 fputs() 将其打印到标准输出。然后打印到它正在等待的事件还有多少分钟。

#include <time.h>
#include <stdio.h>
...
time_t now;
int minutes_to_event;
...
time(&now);
printf("The time is ");
fputs(asctime(localtime(&now)), stdout);
printf("There are still %d minutes to the event.\n",
    minutes_to_event);
...

[h4_00015] 应用程序用法 (APPLICATION USAGE)

[p_00016] puts() 函数会追加一个 <newline>，而 fputs() 不会。

[p_00017] 本卷 POSIX.1-2024 要求成功完成时简单地返回一个非负整数。对于此要求，已知至少有三种不同的实现约定：

  • [p_00018] 返回一个常量值。

  • [p_00019] 返回最后写入的字符。

  • [p_00020] 返回写入的字节数。注意，对于长于 {INT_MAX} 字节的字符串，无法遵循此实现约定，因为该值将无法在函数的返回类型中表示。为了向后兼容，实现可以对不超过 {INT_MAX} 字节的字符串返回字节数，并对所有更长的字符串返回 {INT_MAX}。

[h4_00021] 理由 (RATIONALE)

[p_00022] fputs() 函数是其源代码在引用的The C Programming Language中被指定的函数之一。在最初版本中，该函数没有定义的返回值，但许多实际实现会作为副作用返回最后写入的字符的值，因为那是用作返回值的累加器中剩余的值。在该书的第二版中，根据 ferror() 的返回值，将返回固定值 0 或 EOF；然而，为了与现存实现兼容，一些实现会在成功时返回表示最后写入字节的正值。
