XSH 函数：connect()

名称 (NAME)

connect — 连接套接字 (connect — connect a socket)

摘要 (SYNOPSIS)

#include <sys/socket.h>

int connect(int socket, const struct sockaddr *address,
socklen_t address_len);

说明 (DESCRIPTION)

connect() 函数应尝试在连接模式套接字上建立连接，或者设置或重置无连接模式套接字的对端地址。该函数接受以下参数：

socket
指定与套接字关联的文件描述符。
address
指向包含对端地址的 sockaddr 结构。地址的长度和格式取决于套接字的地址族。
address_len
指定由 address 参数指向的 sockaddr 结构的长度。

如果套接字的地址族是 AF_UNIX，应用程序应确保作为 sockaddr_un 结构的 address 的 sun_path 成员中包含路径名之后的空终止符，并且 address_len 至少为 offsetof(struct sockaddr_un, sun_path) + 1 加上路径名的长度。

如果套接字尚未绑定到本地地址，connect() 应将其绑定到一个地址，除非套接字的地址族是 AF_UNIX，否则该地址是未使用的本地地址。

如果发起套接字不是连接模式的，则 connect() 应设置套接字的对端地址，并且不建立连接。对于 SOCK_DGRAM 套接字，对端地址标识了后续 send() 函数中所有数据报的发送目的地，并限制了后续 recv() 函数的远程发送方。如果 address 的 sa_family 成员是 AF_UNSPEC，则套接字的对端地址应被重置。请注意，尽管没有建立连接，术语 "connected" 仍用于描述已设置了对端地址的无连接模式套接字。

如果发起套接字是连接模式的，则 connect() 应尝试建立到由 address 参数指定的地址的连接。如果连接无法立即建立，并且未为套接字的文件描述符设置 O_NONBLOCK，则 connect() 应阻塞最多一个未指定的超时间隔，直到连接建立。如果超时间隔在连接建立之前到期，则 connect() 应失败，并且连接尝试应被中止。如果在阻塞等待建立连接时 connect() 被一个已捕获的信号中断，则 connect() 应失败并将 errno 设置为 [EINTR]，但连接请求不应被中止，连接应异步建立。

如果连接无法立即建立，并且为套接字的文件描述符设置了 O_NONBLOCK，则 connect() 应失败并将 errno 设置为 [EINPROGRESS]，但连接请求不应被中止，连接应异步建立。在连接建立之前，针对同一套接字对 connect() 的后续调用应失败并将 errno 设置为 [EALREADY]。

当连接已异步建立时，pselect()、select()、poll() 和 ppoll() 应指示套接字的文件描述符已准备好进行写入。

所使用的套接字可能要求进程拥有适当的权限才能使用 connect() 函数。

返回值 (RETURN VALUE)

成功完成后，connect() 应返回 0；否则，应返回 -1，并设置 errno 以指示错误。

错误 (ERRORS)

在以下情况下，connect() 函数应失败：

[EADDRNOTAVAIL]
指定的地址在本地机器上不可用。
[EAFNOSUPPORT]
对于指定套接字的地址族，指定的地址不是有效地址。
[EALREADY]
针对指定套接字的连接请求已在进行中。
[EBADF]
socket 参数不是有效的文件描述符。
[ECONNREFUSED]
目标地址未在侦听连接，或拒绝了连接请求。
[EINPROGRESS]
为套接字的文件描述符设置了 O_NONBLOCK，且连接无法立即建立；连接应异步建立。
[EINTR]
建立连接的尝试被一个已捕获的信号的传递所中断；连接应异步建立。
[EISCONN]
指定的套接字是连接模式的，并且已连接。
[ENETUNREACH]
不存在到达该网络的路由。
[ENOTSOCK]
socket 参数不引用套接字。
[EPROTOTYPE]
指定的地址与绑定到指定对端地址的套接字具有不同的类型。
[ETIMEDOUT]
连接尝试在建立连接之前超时。

如果套接字的地址族是 AF_UNIX，则 connect() 在以下情况下应失败：

[EIO]
在读取或写入文件系统时发生 I/O 错误。
[ELOOP]
在解析 address 中的路径名时遇到的符号链接中存在循环。
[ENAMETOOLONG]
路径名某个组件的长度长于 {NAME_MAX}。
[ENOENT]
路径名的某个组件未指向现有文件，或路径名是空字符串。
[ENOTDIR]
address 中路径名的路径前缀的某个组件指向一个既不是目录也不是指向目录的符号链接的现有文件，或者 address 中的路径名包含至少一个非 <slash> 字符并以一个或多个尾随的 <slash> 字符结尾，且最后一个路径名组件指向一个既不是目录也不是指向目录的符号链接的现有文件。

在以下情况下，connect() 函数可以失败：

[EACCES]
路径前缀的某个组件的搜索权限被拒绝；或对命名套接字的写访问被拒绝。
[EADDRINUSE]
尝试建立使用已被占用的地址的连接。
[ECONNRESET]
远程主机重置了连接请求。
[EHOSTUNREACH]
无法到达目标主机（可能是因为主机已关闭，或远程路由器无法到达它）。
[EINVAL]
address_len 参数对于该地址族不是有效长度；或者 sockaddr 结构中的地址族无效。
[ELOOP]
在解析 address 中的路径名时遇到的符号链接超过 {SYMLOOP_MAX} 个。
[ENAMETOOLONG]
路径名的长度超过 {PATH_MAX}，或符号链接的路径名解析产生的中间结果的长度超过 {PATH_MAX}。
[ENETDOWN]
用于到达目标的本地网络接口已关闭。
[ENOBUFS]
没有可用的缓冲区空间。
[EOPNOTSUPP]
套接字正在侦听，无法被连接。

示例 (EXAMPLES)

无。

应用程序使用 (APPLICATION USAGE)

如果 connect() 失败，套接字的状态是未指定的。符合标准的应用程序宜在尝试重新连接之前关闭文件描述符并创建一个新的套接字。

对于 AF_UNIX 套接字，某些实现支持一种扩展，其中 address_len 不必为存储在 sun_path 中的路径名包含空终止符，这反过来允许路径名长一个字节。但是，此类用法不可移植，并且存在访问超出路径名长度预期边界之外的风险。
