XSH 函数：getsockopt()

名称 (NAME)

getsockopt — 获取套接字选项 (getsockopt — get the socket options)

摘要 (SYNOPSIS)

#include <sys/socket.h>

int getsockopt(int socket, int level, int option_name,
void *restrict option_value, socklen_t *restrict option_len);

说明 (DESCRIPTION)

getsockopt() 函数操作与套接字关联的选项。

getsockopt() 函数应检索由 option_name 参数指定的、针对由 socket 参数指定的套接字的选项的值。如果选项值的大小大于 option_len，则存储在由 option_value 参数指向的对象中的值应被静默截断。否则，应修改由 option_len 参数指向的对象，以指示值的实际长度。

level 参数指定选项所在的协议层。要在套接字层检索选项，请将 level 参数指定为 SOL_SOCKET。要在其他层检索选项，请为控制该选项的协议提供相应的层标识符。例如，要指示选项由 TCP（传输控制协议）解释，请将 level 设置为 <netinet/in.h> 头文件中定义的 IPPROTO_TCP。

所使用的套接字可能要求进程拥有适当的权限才能使用 getsockopt() 函数。

option_name 参数指定要检索的单个选项。它可以是 <sys/socket.h> 中定义并在 2.10.16 选项的使用 中描述的套接字层选项之一。

返回值 (RETURN VALUE)

成功完成后，getsockopt() 应返回 0；否则，应返回 -1，并设置 errno 以指示错误。

错误 (ERRORS)

在以下情况下，getsockopt() 函数应失败：

[EBADF]
socket 参数不是有效的文件描述符。
[EINVAL]
指定的选项在指定的套接字层无效。
[ENOPROTOOPT]
协议不支持该选项。
[ENOTSOCK]
socket 参数不引用套接字。

在以下情况下，getsockopt() 函数可以失败：

[EACCES]
调用进程没有适当的权限。
[EINVAL]
套接字已被关闭。
[ENOBUFS]
系统中可用于完成该函数的资源不足。
