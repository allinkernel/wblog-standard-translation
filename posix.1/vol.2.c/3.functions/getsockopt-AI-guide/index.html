XSH 函数导读：getsockopt()

0. 总览

getsockopt() 获取套接字选项：检索由 option_name 指定的、针对指定套接字的选项的当前值。头文件为 <sys/socket.h>，原型为 int getsockopt(int socket, int level, int option_name, void *restrict option_value, socklen_t *restrict option_len)。成功返回 0，失败返回 -1 并设置 errno。

1. 机制

level 指定选项所在的协议层：在套接字层检索选项时置为 SOL_SOCKET；在协议层检索时提供控制该选项的协议层标识符，例如想让 TCP 解释选项就把 level 设为 <netinet/in.h> 中定义的 IPPROTO_TCP。option_name 可以是 <sys/socket.h> 中定义并在"2.10.16 选项的使用"中描述的套接字层选项（如 SO_SNDBUF、SO_RCVTIMEO 等）。option_len 是"值-结果"参数：输入时给出 option_value 缓冲区的长度，如果选项值的实际大小更大，值被静默截断；否则 option_len 被修改为实际长度。与 setsockopt() 配对使用：先查询默认值或当前值，再按需修改。

2. 易错点

  • 必须初始化 option_len 为 option_value 缓冲区大小，否则结果不可靠，甚至因长度小于选项所需而返回截断值。
  • 选项在指定套接字层无效返回 [EINVAL]；协议不支持该选项返回 [ENOPROTOOPT]；level 传错层（如把套接字层选项放到 IPPROTO_TCP）是常见错误。
  • 值大于缓冲区时被静默截断，不会报错，注意区分选项类型（int、linger 结构等）并给出足够大的缓冲区。
  • 描述符不是套接字返回 [ENOTSOCK]；某些选项可能需要适当权限，失败可能返回 [EACCES]。

3. 示例

#include <sys/socket.h>

int sndbuf;
socklen_t optlen = sizeof(sndbuf);

if (getsockopt(sfd, SOL_SOCKET, SO_SNDBUF,
               &sndbuf, &optlen) == -1) {
    /* EINVAL、ENOPROTOOPT、ENOTSOCK 等 */;
}
