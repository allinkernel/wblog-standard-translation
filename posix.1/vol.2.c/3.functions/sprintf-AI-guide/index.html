XSH 函数导读：sprintf()

0. 总览

sprintf() 打印格式化输出到字符串：在 format 控制下转换、格式化并打印其参数，把输出及随后的空字节 '\0' 放到从 *s 开始的连续字节中。头文件为 <stdio.h>。原型关键点：int sprintf(char *restrict s, const char *restrict format, ...)——目标缓冲区是调用者提供的 s，确保有足够空间可用是用户的责任；成功时返回写入 s 的字节数（不包括终止空字节），遇到错误返回负值并设置 errno。

1. 机制

格式化输出的核心行为与 printf() 家族一致：format 由普通字符与转换说明组成，转换说明由 % 引入，后接标志、可选最小字段宽度、可选精度、可选长度修饰符（hh、h、l、ll、j、z、t、L）和转换说明符（d、i、o、u、x、X、f、F、e、E、g、G、a、A、c、s、p、n、%）。与输出到流的兄弟函数不同，sprintf() 直接把字节写入内存数组并在末尾追加 '\0'，没有缓冲、刷新问题。返回值是实际写入的字节数（不含结尾空字节），可用于计算字符串长度。若因调用 sprintf() 而在重叠的对象之间进行复制，结果是未定义的。

2. 易错点

常见坑：一是 sprintf() 完全没有长度限制——若目标缓冲区不够大，就会越界写坏内存，这是缓冲区溢出漏洞的经典来源，新代码应优先用 snprintf()；二是返回值不含终止空字节，计算所需缓冲区大小时要 +1；三是 %s 无精度时源字符串必须以空字节结尾，否则越界读取；四是格式字符串与参数个数/类型不匹配是未定义行为；五是 %n 会把已写字节数写入指针参数，可被滥用做任意内存写，慎用；六是不要把 sprintf() 的输出缓冲区与其格式字符串或输入参数重叠，那会触发未定义行为。

3. 示例

#include <stdio.h>

int main(void) {
    char buf[64];
    int len;

    len = sprintf(buf, "count=%d\n", 10);
    /* buf: "count=10\n\0"；len == 9（不含结尾空字节） */

    if (len < 0)
        return 1;   /* 输出错误 */
    return 0;
}
