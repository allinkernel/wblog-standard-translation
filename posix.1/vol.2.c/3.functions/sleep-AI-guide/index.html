XSH 函数导读：sleep()

0. 总览

sleep() 使调用线程挂起执行，直到 seconds 秒实时时间经过，或直到信号被传递给调用线程且其动作是调用信号捕获函数或终止进程。头文件为 <unistd.h>。原型关键点：unsigned sleep(unsigned seconds)——参数与返回值都是 unsigned；未定义任何错误。

1. 机制

挂起时间可能因系统调度其他活动而长于请求值。返回规则：时间到则返回 0；被信号传递打断则返回"未睡足"的时间量（请求时间减实际睡眠时间，以秒计）。实现方式：单线程程序可用 SIGALRM（如 alarm()+sigsuspend()）实现，多线程程序中不应使用 SIGALRM。标准对基于 SIGALRM 的实现提出严格要求：必须妥善处理先前 alarm() 调度的 SIGALRM、SIGALRM 的动作与阻塞状态——已调度在更早时刻的 SIGALRM 必须缩短睡眠并在返回前生成，调度在更晚时刻的则须在返回前重排到原时刻，动作与阻塞须保存并恢复。

2. 易错点

  • 与 alarm()/SIGALRM 交互：睡眠期间若 SIGALRM 被忽略或阻塞而无法传递，sleep() 是否在 SIGALRM 被调度时返回未指定，返回后该信号保持待决还是被丢弃也未指定。先前的 alarm() 会强制 sleep() 提前返回。
  • 处理程序内探查 SIGALRM 状态：被信号捕获函数中断后，若处理程序检查/更改 SIGALRM 的调度时间、动作或阻塞状态，结果未指定；用 siglongjmp()/longjmp() 跳出的后果同样未指定。
  • 多线程：多线程程序中的 sleep() 不应使用 SIGALRM，别依赖它与 alarm() 的协同。
  • 类型限制：与 alarm() 相同，可移植传值不超过 {UINT_MAX} 最小保证值（65535）。
  • 调度延迟：实际睡眠超过请求时间时返回值按公式（请求 − 实际）为负，但因返回 unsigned，规定此时返回 0。
  • 精度：需要亚秒精度时用 nanosleep()。

3. 示例

#include <unistd.h>
#include <stdio.h>

int main(void) {
    unsigned left = sleep(10);
    if (left != 0) {
        /* 被信号打断：left 为未睡足的秒数 */
        printf("被打断，剩余 %u 秒\n", left);
    }
    return 0;
}
