XSH 函数：pthread_self()

名称 (NAME)

pthread_self — 获取调用线程的线程 ID (get the calling thread ID)

简介 (SYNOPSIS)

#include <pthread.h>

pthread_t pthread_self(void);

描述 (DESCRIPTION)

pthread_self() 函数应返回调用线程的线程 ID。

返回值 (RETURN VALUE)

pthread_self() 函数应始终成功，并且不保留任何返回值来指示错误。

错误 (ERRORS)

未定义错误。

The following sections are informative.

示例 (EXAMPLES)

无。

应用用法 (APPLICATION USAGE)

无。

理由 (RATIONALE)

pthread_self() 函数提供了与进程的 getpid() 函数类似的能力，理由也相同：创建调用不会向所创建的线程提供线程 ID。

未来方向 (FUTURE DIRECTIONS)

无。

第 7 版 (Issue 7)

pthread_self() 函数从 Threads 选项移至 Base。
