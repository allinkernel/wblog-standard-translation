XSH 函数导读：setenv()

0. 总览

setenv() 用于添加或更改调用进程环境中的一个环境变量。头文件为 <stdlib.h>（本函数属 [CX] 选项）。原型：int setenv(const char *envname, const char *envval, int overwrite)——前两个参数分别给出变量名与值，第三个参数控制是否覆盖已存在的同名变量。

1. 机制

函数更新或添加进程环境中的一个变量：envname 命名要设置的变量，envval 给出值。若 envname 中含 '=' 字符则调用失败。若同名变量已存在：overwrite 非零则更新环境，为零则返回成功但环境保持不变。函数会更新外部指针列表 environ，并复制 envname 与 envval 所指的字符串。规范明确本函数不必是线程安全的。失败时返回 -1、设置 errno，且环境保持不变。

2. 易错点

  • overwrite 为 0 时“返回成功但环境保持不变”，容易误以为值已写入；要真正覆盖必须传非零。
  • envname 为空字符串或含 '=' 时返回 [EINVAL]；内存不足时返回 [ENOMEM]。
  • 函数可能更改 environ，而 main() 的可选 envp 参数及其他副本不会更新，可能仍指向环境的过时版本。
  • 多线程应用中更改环境的限制参见 exec() 的说明，且本函数本身不必是线程安全的。

3. 示例

#include <stdlib.h>
#include <stdio.h>

int main(void) {
    /* overwrite 非零：无论变量是否已存在都更新 */
    if (setenv("MY_VAR", "hello", 1) == -1) {
        perror("setenv");
        return 1;
    }
    printf("%s\n", getenv("MY_VAR"));
    return 0;
}
