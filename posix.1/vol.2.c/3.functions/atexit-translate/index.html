XSH 函数：atexit()

名称 (NAME)

atexit — 注册一个将从 .I exit () 调用或在从 .I main () 返回后调用的函数 (register a function to be called from .I exit () or after return from .I main ())

概要 (SYNOPSIS)

#include <stdlib.h>

int atexit(void (*func)(void));

说明 (DESCRIPTION)

[CX] The functionality described on this reference page is aligned with the ISO C standard. Any conflict between the requirements described here and the ISO C standard is unintentional. This volume of POSIX.1-2024 defers to the ISO C standard.

atexit() 函数应注册由 func 指向的函数，该函数将从 exit() 无参数调用，或在从对 main() 的初始调用返回后调用，或在最后一个线程终止时调用。如果调用了 exit() 函数，则在调用 exit() 之前未发生的对 atexit() 函数的调用是否会成功是未指定的。

至少可以用 atexit() 注册 32 个函数。

返回值 (RETURN VALUE)

成功完成后，atexit() 应返回 0；否则，它应返回非零值。

错误 (ERRORS)

未定义任何错误。

示例 (EXAMPLES)

无。

应用程序用法 (APPLICATION USAGE)

atexit() 函数的注册与 at_quick_exit() 的注册不同，因此应用程序可能需要用相同的参数调用两个注册函数。

由调用 atexit() 注册的函数必须返回以确保所有注册的函数都被调用。

应用程序应调用 sysconf() 以获得 {ATEXIT_MAX} 的值，即可以注册的函数的数量。应用程序无法得知已经用 atexit() 注册了多少函数。

由于多次调用 exit() 函数时行为是未定义的，调用 atexit() 的可移植应用程序必须确保在调用由 atexit() 函数注册的函数时不调用 exit() 函数。

如果由 atexit() 函数注册的函数被调用，并且可移植应用程序需要停止进一步的 exit() 处理，它必须调用 _exit() 函数或 _Exit() 函数或导致异常进程终止的函数之一。
