XSH 函数导读：pthread_create()

0. 总览

pthread_create() 在进程内创建一个新线程，是 POSIX 线程编程的入口。头文件为 <pthread.h>。原型关键点：int pthread_create(pthread_t *restrict thread, const pthread_attr_t *restrict attr, void *(*start_routine)(void*), void *restrict arg)——thread 接收新线程 ID，attr 指定属性（NULL 表示默认属性），新线程从执行 start_routine 开始并以 arg 作为其唯一参数。成功返回 0，失败返回错误号（而非 -1）。

1. 机制

新线程以 arg 调用 start_routine；若 start_routine 返回，效果如同隐式调用 pthread_exit() 并把返回值作为退出状态（注意：main() 返回则如同调用 exit()，语义不同）。attr 指定的属性在创建时被快照，之后修改属性对象不影响已创建的线程。信号状态：新线程的信号掩码从创建线程继承，但挂起信号集为空；线程局部的当前区域设置与备用栈不被继承，浮点环境从创建线程继承。若定义 _POSIX_THREAD_CPUTIME，新线程有初始值为零的可访问 CPU 时间时钟。失败时不创建线程，thread 所指位置的内容未定义。若 attr 未指向已初始化的属性对象，行为未定义（建议实现报告 [EINVAL]）。

2. 易错点

  • 错误返回方式：失败返回错误号（如 [EAGAIN]：资源不足或超过 {PTHREAD_THREADS_MAX}；[EPERM]：无权限设置调度参数/策略），不是 -1，不要用 perror() 直接处理。
  • ID 可用时机：实现不要求新线程 ID 在新线程开始执行前就可用；创建线程经 thread 参数获取 ID，新线程自己用 pthread_self() 获取，别假设两者次序。
  • 信号掩码继承：新线程继承创建者的掩码——多线程信号处理的典型做法是先在创建者里阻塞信号，再让新线程 sigwait()。
  • 未初始化 attr：传入未初始化的 pthread_attr_t 是未定义行为，务必先用 pthread_attr_init() 初始化。
  • 栈与局部状态：备用栈、线程局部当前区域设置不被继承；浮点环境则继承。
  • 不应返回 [EINTR]：该函数不应返回 [EINTR] 错误码。

3. 示例

#include <pthread.h>
#include <stdio.h>

static void *worker(void *arg) {
    long n = (long)arg;   /* 参数经 arg 传入 */
    printf("worker: %ld\n", n);
    return (void *)0;     /* 等同 pthread_exit(0) */
}

int main(void) {
    pthread_t tid;
    int rc = pthread_create(&tid, NULL, worker, (void *)42);
    if (rc != 0) {
        fprintf(stderr, "pthread_create: %d\n", rc);
        return 1;
    }
    pthread_join(tid, NULL);
    return 0;
}
