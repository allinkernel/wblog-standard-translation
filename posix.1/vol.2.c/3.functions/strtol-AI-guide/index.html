XSH 函数导读：strtol()

0. 总览

strtol() 将字符串转换为长整数：把 nptr 指向的字符串的初始部分按 base 指定的基数转换成 long（另有 strtoll() 转 long long）。头文件为 <stdlib.h>。原型关键点：long strtol(const char *restrict nptr, char **restrict endptr, int base)——endptr 用于报告转换停止的位置，可为空指针。

1. 机制

输入被分解为三部分：可能为空的初始空白序列、被解释为整数的“主题序列”、以及最终字符串（含终止 NUL）。base 为 0 时按 C 字面量规则自动判定：0x/0X 开头按十六进制、0 开头按八进制、其余按十进制；base 为 2–36 时按该基数解释，字母 a–z（或大写）取值 10–35，只允许值小于 base 的字母（base 为 16 时可带 0x 前缀）。主题序列是从第一个非空白字节开始、具有期望形式的最长初始子序列；若为空或不具期望形式，则不转换，并把 nptr 原值存入 *endptr。以 <hyphen-minus> 开头时结果为相反数。成功时函数不改变 errno 的设置；超出可表示范围返回 {LONG_MIN}/{LONG_MAX}（或 LLONG 版）并置 errno 为 [ERANGE]；不支持的 base 返回 0 并置 [EINVAL]。

2. 易错点

  • 0、{LONG_MIN}、{LONG_MAX} 既可能是错误返回值也可能是合法成功值：应先把 errno 置 0，调用后再查 errno 区分。
  • 无法转换时返回 0，且 errno 可能被置为 [EINVAL]——“输入不是数字”与“数字是 0”要靠 endptr 判定：若 endptr == nptr 说明主题序列为空。
  • 检查 endptr 时不要忘记非数字后缀："42abc" 会成功转换出 42，*endptr 指向 'a'；需要“整串都是数字”时须检查 *endptr == '\0'。
  • base 不受支持时 *endptr 的值未指定：应在调用前保证 base 为 0 或 2–36，或在检查 *endptr 前先检查 [EINVAL]。
  • 返回值是 long，用 atoi() 的习惯直接赋给 int 可能截断；base 为 0 时 "08" 之类会按八进制解析失败或异常。
  • 负数超范围返回 {LONG_MIN}、正数超范围返回 {LONG_MAX}，[ERANGE] 时不能把返回值当真实值。

3. 示例

#include <errno.h>
#include <stdlib.h>
#include <stdio.h>

int main(void)
{
    const char *s = "  0x1F 尾随文字";
    char *end;
    long v;

    errno = 0;                 /* 必须清零以检测错误 */
    v = strtol(s, &end, 0);    /* base=0：自动识别 0x 前缀 */
    if (errno == ERANGE) {
        puts("超出 long 范围");
    } else if (end == s) {
        puts("没有可转换的数字");
    } else {
        printf("值=%ld，余下: %s\n", v, end);
    }
    return 0;
}
