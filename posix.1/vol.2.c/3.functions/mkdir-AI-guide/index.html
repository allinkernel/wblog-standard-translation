XSH 函数导读：mkdir()

0. 总览

mkdir() 用于创建目录。头文件为 <sys/stat.h>；扩展函数 mkdirat() 还需 <fcntl.h>。原型：int mkdir(const char *path, mode_t mode)、int mkdirat(int fd, const char *path, mode_t mode)。

1. 机制

函数创建名为 path 的新目录。文件权限位及（XSI 选项下）S_ISVTX 位由 mode 初始化，且 mode 的文件权限位会被进程的文件创建掩码（umask）修改；mode 中其他位的含义是实现定义的。新目录的用户 ID 被设置为进程的有效用户 ID，组 ID 被设置为父目录的组 ID 或进程的有效组 ID（实现须提供一种继承父目录组 ID 的方式）。新创建的目录是空目录。若 path 命名符号链接，则失败并置 [EEXIST]。返回 -1 时不应创建任何目录。

2. 易错点

  • 目录已存在（包括 path 是符号链接）时返回 [EEXIST]，不是“自动跳过”。
  • 父目录被拒绝写权限 [EACCES]、路径前缀组件不存在 [ENOENT]、文件系统空间不足 [ENOSPC] 是常见失败。
  • 组 ID 不保证取父目录还是有效组 ID，符合规范的应用程序不应假定；如重要可事后用 chown() 设置。
  • mkdir() 不会递归创建缺失的中间目录；mode 中非权限位的含义不可移植。
  • 最后一个组件含换行字符编码值的字节时，实现被鼓励报告 [EILSEQ]。

3. 示例

#include <sys/stat.h>
#include <stdio.h>

int main(void) {
    /* 所有者读/写/搜索，组读/搜索，其他读/搜索（再经 umask 修正） */
    if (mkdir("/home/cnd/mod1", S_IRWXU | S_IRWXG | S_IROTH | S_IXOTH) == -1)
        perror("mkdir");
    return 0;
}
