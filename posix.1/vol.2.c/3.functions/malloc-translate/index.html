XSH 函数：malloc()

名称 (NAME)

malloc — 内存分配器

摘要 (SYNOPSIS)

#include <stdlib.h>

void *malloc(size_t size);

说明 (DESCRIPTION)

[CX] The functionality described on this reference page is aligned with the ISO C standard. Any conflict between the requirements described here and the ISO C standard is unintentional. This volume of POSIX.1-2024 defers to the ISO C standard.

malloc() 函数应为对象分配未使用的空间，该对象的大小（以字节计）由 size 指定，其值未指定。

对 malloc() 的连续调用所分配的存储的顺序和连续性未指定。若分配成功，返回的指针应适当对齐，使其可以赋给具有基础对齐要求的任何类型对象的指针，并用于访问所分配空间中此类对象（直到该空间被显式释放或重新分配）。每次此类分配应产生一个与其他任何对象不相交的对象的指针。返回的指针指向所分配空间的起始位置（最低字节地址）。若无法分配空间，应返回空指针。若所请求的空间大小为 0，则行为是实现定义的：或者返回空指针，或者行为如同大小是某个非零值，但若使用返回的指针访问对象，则行为未定义。

为确定数据竞争是否存在，malloc() 应表现得如同只访问了通过其参数可访问的内存位置，而不访问其他静态存储期存储。但该函数可以明显地修改其分配到的存储。分配或释放特定内存区域的 aligned_alloc()、calloc()、free()、malloc()、[ADV] posix_memalign()、 [CX] reallocarray()、 以及 realloc() 调用应按单一全序发生（参见 4.15.1 内存排序），并且每次此类释放调用应与此顺序中的下一次分配（若有）同步。

返回值 (RETURN VALUE)

成功完成时，malloc() 应返回指向所分配空间的指针；若 size 为 0，应用程序应确保不使用该指针访问对象。

否则，它应返回空指针 [CX] 并设置 errno 以指示错误。

错误 (ERRORS)

malloc() 函数在以下情况下应失败：

[ENOMEM]
[CX] 可用的存储空间不足。

malloc() 函数在以下情况下可以失败：

[EINVAL]
[CX] size 为 0 且实现不支持 0 大小的分配。

原理 (RATIONALE)

一些实现将 errno 设置为 [EAGAIN] 以表示重试后可能成功的内存分配失败，并设置为 [ENOMEM] 以表示不太可能成功的失败，例如由于配置的限制。2.3 错误编号 允许此行为；当多个错误条件同时为真时，它们之间没有优先级。
