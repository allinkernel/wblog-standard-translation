XSH 函数：fwrite()

[h4_00001] 名称 (NAME)

[blockquote_00002] fwrite — 二进制输出 (binary output)

[h4_00003] 提要 (SYNOPSIS)

[p_00004] #include <stdio.h>

size_t fwrite(const void *restrict ptr, size_t size, size_t nitems,
FILE *restrict stream);

[h4_00005] 说明 (DESCRIPTION)

[CX] The functionality described on this reference page is aligned with the ISO C standard. Any conflict between the requirements described here and the ISO C standard is unintentional. This volume of POSIX.1-2024 defers to the ISO C standard.

[p_00006] fwrite() 函数应从 ptr 指向的数组中，将至多 nitems 个大小由 size 指定的元素写入 stream 指向的流。对于每个对象，应调用 fputc() 函数 size 次，从恰好覆盖该对象的 unsigned char 数组中（按顺序）取值。流的文件位置指示符（如果已定义）应按成功写入的字节数前进。如果发生错误，则流的文件位置指示符的结果值未指定。

[p_00007] [CX] 文件的上次数据修改和上次文件状态更改时间戳应被标记更新，在 fwrite() 成功执行与对同一流调用 fflush() 或 fclose() 的下一次成功完成之间，或与调用 exit() 或 abort() 之间。

[h4_00008] 返回值 (RETURN VALUE)

[p_00009] fwrite() 函数应返回成功写入的元素数，只有在遇到写入错误时，该数才应小于 nitems。如果 size 或 nitems 为 0，则 fwrite() 应返回 0，并且流的状态保持不变。否则，如果发生写入错误，应设置流的错误指示符，[CX] 并应设置 errno 以指示错误。

[h4_00010] 错误 (ERRORS)

[p_00011] 参见 fputc()。

The following sections are informative.

[h4_00014] 应用程序用法 (APPLICATION USAGE)

[p_00015] 由于元素长度和字节顺序可能存在差异，使用 fwrite() 写入的文件是应用程序相关的，并且可能无法由不同的应用程序或在不同的处理器上运行的同一应用程序使用 fread() 读取。
