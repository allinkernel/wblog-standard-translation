XSH 函数：fgets()

[h4_00001] 名称 (NAME)

[blockquote_00002] fgets — 从流中获取字符串 (get a string from a stream)

[h4_00003] 提要 (SYNOPSIS)

[p_00004] #include <stdio.h>

char *fgets(char *restrict s, int n, FILE *restrict stream);

[h4_00005] 说明 (DESCRIPTION)

[CX] The functionality described on this reference page is aligned with the ISO C standard. Any conflict between the requirements described here and the ISO C standard is unintentional. This volume of POSIX.1-2024 defers to the ISO C standard.

[p_00006] fgets() 函数应从 stream 读取字节到 s 指向的数组中，直到读取了 n-1 个字节，或读取到一个 <newline> 并将其传送到 s，或遇到文件末尾条件。在读取到数组中的最后一个字节之后，应立即写入一个空字节。如果在读取任何字节之前遇到文件末尾条件，则 s 指向的数组的内容不应被改变。

[p_00007] [CX] fgets() 函数可以标记更新与 stream 关联的文件的上次数据访问时间戳。当使用 stream 的 fgetc()、fgets()、fread()、fscanf()、getc()、getchar()、getdelim()、getline() 或 scanf() 首次成功执行并返回了不是由先前对 ungetc() 的调用提供的数据时，上次数据访问时间戳应被标记更新。

[h4_00008] 返回值 (RETURN VALUE)

[p_00009] 成功完成后，fgets() 应返回 s。如果流位于文件末尾，则应设置流的文件末尾指示符，并且 fgets() 应返回空指针。如果发生错误，应设置流的错误指示符，fgets() 应返回空指针，[CX] 并应设置 errno 以指示错误。

[h4_00010] 错误 (ERRORS)

[p_00011] 参见 fgetc()。

The following sections are informative.

[h4_00012] 示例 (EXAMPLES)

[h5_00013] 读取输入 (Reading Input)

[p_00014] 以下示例使用 fgets() 读取输入行。它假设它正在读取的文件是文本文件，并且该文本文件中的行长度不超过 16384（或者如果在其运行所在的实现上小于 16384，则为 {LINE_MAX}）字节。（注意，如果 sysconf(_SC_LINE_MAX) 返回 -1 而未设置 errno，则标准实用程序没有行长度限制。此示例假设 sysconf(_SC_LINE_MAX) 不会失败。）

#include <limits.h>
#include <stdio.h>
#include <unistd.h>
#define MYLIMIT 16384
 
char *line;
int line_max;
if (LINE_MAX >= MYLIMIT) {
    // Use maximum line size of MYLIMIT. If LINE_MAX is
    // bigger than our limit, sysconf() cannot report a
    // smaller limit.
    line_max = MYLIMIT;
} else {
    long limit = sysconf(_SC_LINE_MAX);
    line_max = (limit < 0 || limit > MYLIMIT) ? MYLIMIT : (int)limit;
}
 
// line_max + 1 leaves room for the null byte added by fgets().
line = malloc(line_max + 1);
if (line == NULL) {
    // out of space
    ...
    return error;
}
 
while (fgets(line, line_max + 1, fp) != NULL) {
    // Verify that a full line has been read ...
    // If not, report an error or prepare to treat the
    // next time through the loop as a read of a
    // continuation of the current line.
    ...
    // Process line ...
    ...
}
free(line);
