XSH 函数导读：rename()

0. 总览

rename() 用于重命名文件，也支持重命名目录。头文件为 <stdio.h>；扩展函数 renameat() 还需 <fcntl.h>。原型：int rename(const char *old, const char *new)、int renameat(int oldfd, const char *old, int newfd, const char *new)。

1. 机制

函数把 old 命名的文件改名为 new。对符号链接操作的是链接本身，不解析最后一个组件：old 是符号链接则重命名该链接，new 是符号链接则移除该链接。若 new 已存在，则移除它再把 old 重命名为 new，且整个操作要求原子：名为 new 的目录项在整个重命名期间保持对其他线程可见。old 与 new 解析到同一目录项时成功且不执行其他操作。若 old 是目录而 new 是文件（或反之），或 new 是非空目录，则失败。old 不应命名 new 的祖先目录，任一最终组件为 dot 或 dot-dot 的路径也失败。

2. 易错点

  • 同名 new 会被静默覆盖（原子替换），与“先 unlink 再 link”不同；需要保留旧内容时务必先备份。
  • 跨文件系统时失败 [EXDEV]（实现不支持文件系统间硬链接时）。
  • 目录对目录：new 必须不存在或是空目录，否则 [EEXIST] 或 [ENOTEMPTY]；类型不匹配时返回 [EISDIR]/[ENOTDIR]。
  • old 是 new 的祖先目录或出现 dot/dot-dot 最终组件时返回 [EINVAL]。
  • 失败时（[EIO] 以外）new 命名的任何文件不受影响。

3. 示例

#include <stdio.h>

int main(void) {
    /* new 已存在时会被原子替换 */
    if (rename("/home/cnd/mod1", "/home/cnd/mod2") == -1)
        perror("rename");
    return 0;
}
