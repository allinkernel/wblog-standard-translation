XSH 函数：setsockopt()

名称 (NAME)

setsockopt — 设置套接字选项 (setsockopt — set the socket options)

摘要 (SYNOPSIS)

#include <sys/socket.h>

int setsockopt(int socket, int level, int option_name,
const void *option_value, socklen_t option_len);

说明 (DESCRIPTION)

setsockopt() 函数应将由 option_name 参数指定的选项，在由 level 参数指定的协议层上，设置为由 option_value 参数指向的值；该选项用于与由 socket 参数指定的文件描述符相关联的套接字。

level 参数指定选项所在的协议层。要在套接字层设置选项，请将 level 参数指定为 SOL_SOCKET。要在其他层设置选项，请为控制该选项的协议提供相应的 level 标识符。例如，要指示选项由 TCP（传输控制协议）解释，请将 level 设置为 <netinet/in.h> 头文件中定义的 IPPROTO_TCP。

option_name 参数指定要设置的单个选项。它可以是 <sys/socket.h> 中定义并在 2.10.16 选项的使用 中描述的套接字层选项之一。如果 option_name 等于 SO_RCVTIMEO 或 SO_SNDTIMEO 并且实现支持设置该选项，则由 option_value 指向的 struct timeval 是按本函数提供的原样存储，还是向上取整以与所用时钟的分辨率对齐，这是未指定的。如果以 option_name 等于 SO_ACCEPTCONN、SO_ERROR 或 SO_TYPE 调用 setsockopt()，则行为是未指定的。

返回值 (RETURN VALUE)

成功完成后，setsockopt() 应返回 0。否则，应返回 -1，并设置 errno 以指示错误。

错误 (ERRORS)

在以下情况下，setsockopt() 函数应失败：

[EBADF]
socket 参数不是有效的文件描述符。
[EDOM]
发送和接收超时值太大，无法放入套接字结构中的超时字段。
[EINVAL]
指定的选项在指定的套接字层无效，或套接字已被关闭。
[EISCONN]
套接字已连接，并且当套接字已连接时无法设置指定的选项。
[ENOPROTOOPT]
协议不支持该选项。
[ENOTSOCK]
socket 参数不引用套接字。

在以下情况下，setsockopt() 函数可以失败：

[ENOMEM]
没有足够的内存可供操作完成。
[ENOBUFS]
系统中可用于完成调用的资源不足。
The following sections are informative.

示例 (EXAMPLES)

无。

应用程序使用 (APPLICATION USAGE)

setsockopt() 函数为应用程序提供了控制套接字行为的手段。应用程序可以使用 setsockopt() 来分配缓冲区空间、控制超时或允许套接字数据广播。<sys/socket.h> 头文件定义了可供 setsockopt() 使用的套接字层选项。

选项可以存在于多个协议层。SO_ 选项始终存在于最顶层的套接字层。

由 accept() 或 accept4() 从侦听套接字继承到被接受的套接字的套接字选项（如果有）是哪些，这是实现定义的。
