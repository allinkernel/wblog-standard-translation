XSH 函数导读：pthread_exit()

0. 总览

pthread_exit() 终止调用线程，并把退出值交给任何成功的汇合（join）。头文件为 <pthread.h>。原型关键点：_Noreturn void pthread_exit(void *value_ptr);——它永不返回调用者，返回值类型为 void，唯一的参数是作为线程退出状态传给 join 的指针。

1. 机制

调用时，线程先按压入的相反顺序弹出并执行所有尚未弹出的取消清理处理程序（cleanup handler）；之后，若该线程有线程特定数据（pthread_key_t 或 tss_t），以未指定顺序调用相应析构函数。线程终止不会释放进程级资源：互斥量、文件描述符等仍归进程所有，也不会执行 atexit() 例程。当线程从启动例程返回时会隐式调用 pthread_exit()，返回值即退出状态。若最后一个线程终止，进程以状态 0 退出，如同实现在线程终止时以参数零调用 exit()。

2. 易错点

不要把线程局部（auto）变量的引用当作 value_ptr：线程终止后再访问其局部变量结果未定义，join 方拿到的可能是一块已失效的栈地址。不要在取消清理处理程序或析构函数里再调用 pthread_exit()，行为未定义。从 thrd_create() 创建的线程不应调用 pthread_exit()，因为其退出状态类型是 int 而非 void *。若主线程调用它且并非最后终止，其他线程不应试图用 thrd_join() 获取其状态。

3. 示例

#include <pthread.h>
#include <stdio.h>

void *worker(void *arg) {
    pthread_exit((void *)7);   /* 显式终止，永不返回 */
}

int main(void) {
    pthread_t th;
    void *ret = NULL;
    pthread_create(&th, NULL, worker, NULL);
    pthread_join(th, &ret);
    printf("退出值: %ld\n", (long)ret);
    return 0;
}
