XSH 函数导读：unlink()

0. 总览

unlink() 用于移除一个目录项。头文件为 <unistd.h>；扩展函数 unlinkat() 还需 <fcntl.h>。原型：int unlink(const char *path)、int unlinkat(int fd, const char *path, int flag)。

1. 机制

函数移除 path 命名的目录项并递减该目录项所引用文件的链接计数。若 path 是符号链接，移除的是链接本身而不影响其目标。当链接计数变为 0 且没有进程通过打开的文件描述符或内存映射引用该文件时，空间被释放、文件不再可访问；若仍有引用，目录项先被移除，文件内容的移除推迟到所有引用关闭之后。path 不应命名目录，除非进程具有适当特权且实现支持。unlinkat() 相对 fd 关联的目录解析相对路径，传 AT_FDCWD 时使用当前工作目录；设置 AT_REMOVEDIR 标志则按 rmdir() 语义把目录作为目录移除。

2. 易错点

  • 对已打开的文件 unlink 后，目录项虽消失，但通过已有文件描述符仍可继续读写——这正是临时文件常用惯用法的基础。
  • unlink() 不能用来移除目录（返回 [EPERM]）；移除目录应使用 rmdir()。
  • [EBUSY] 表示文件正被系统或另一进程使用（如挂载点、某进程的根或当前工作目录）；正在执行的纯过程文件的最后一个目录项可能返回 [ETXTBSY]。
  • 包含目标的目录设置了 S_ISVTX 标志且进程不满足 XBD 4.5 目录保护条件时，返回 [EPERM] 或 [EACCES]。
  • 返回 -1 时，所命名的文件不应被更改。

3. 示例

#include <unistd.h>
#include <stdio.h>

int main(void) {
    if (unlink("/tmp/tmpfile") == -1)
        perror("unlink");
    return 0;
}
