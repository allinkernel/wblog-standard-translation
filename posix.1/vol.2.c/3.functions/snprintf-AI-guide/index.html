XSH 函数导读：snprintf()

0. 总览

snprintf() 打印格式化输出到字符串并限制长度：等同于 sprintf()，外加 n 参数限制写入 s 所引用缓冲区的字节数。头文件为 <stdio.h>。原型关键点：int snprintf(char *restrict s, size_t n, const char *restrict format, ...)——若 n 为 0，不写入任何内容且 s 可以是空指针；否则超出第 n-1 个的输出字节被丢弃，并在实际写入数组的字节末尾写入一个空字节，保证结果以 '\0' 结尾（当 n > 0 时）。

1. 机制

核心行为：先按 format 完整格式化所有参数，然后受 n 限制仅把前 n-1 个字节写入 s 并补空字节结尾；溢出部分被丢弃，不写坏缓冲区。返回值语义特别重要：成功时返回如果 n 足够大将会写入 s 的字节数（不包括终止空字节）——即完整结果所需的长度，可能大于 n-1。这个"所需长度"可用来判断是否发生截断，以及动态分配多大缓冲区。注意 n 限制的是写入 s 的字节数，它不一定与 s 的大小相同。遇到错误时返回负值并设置 errno。

2. 易错点

常见坑：一是返回值语义——snprintf() 返回的是"如果没有限制将会写入的字节数"，不是实际写入的字节数；返回 n 或更大即说明输出被截断，需要用更大的缓冲区重试或改用动态分配；二是 n 应为缓冲区大小，若传入的 n 大于实际数组大小，仍会越界写；三是不检查返回值就假定字符串完整；四是与 sprintf() 一样，参数类型不匹配、%s 无结尾空字节、重叠复制都属未定义行为；五是 %n 同样应避免。正确用法是分配足够大的缓冲区并检查返回值是否小于 n。

3. 示例

#include <stdio.h>

int main(void) {
    char buf[8];
    int need;

    need = snprintf(buf, sizeof buf, "hello %d", 123456);
    /* 完整结果 "hello 123456" 需 12 字节（不含 '\0'） */

    if (need < 0)
        return 1;                       /* 输出错误 */
    if ((size_t)need >= sizeof buf) {
        /* 已截断：buf 内容为 "hello 1\0"，需扩大缓冲区 */
        return 1;
    }
    return 0;
}
