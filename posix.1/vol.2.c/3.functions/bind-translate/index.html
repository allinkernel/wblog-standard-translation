XSH 函数：bind()

名称 (NAME)

bind — 将名称绑定到套接字 (bind — bind a name to a socket)

摘要 (SYNOPSIS)

#include <sys/socket.h>

int bind(int socket, const struct sockaddr *address,
socklen_t address_len);

说明 (DESCRIPTION)

bind() 函数应将本地套接字地址 address 分配给由描述符 socket 标识的、尚未分配本地套接字地址的套接字。使用 socket() 函数创建的套接字最初是未命名的；它们仅由其地址族标识。

bind() 函数接受以下参数：

socket
指定要绑定的套接字的文件描述符。
address
指向包含要绑定到套接字的地址的 sockaddr 结构。地址的长度和格式取决于套接字的地址族。
address_len
指定由 address 参数指向的 sockaddr 结构的长度。

由 socket 指定的套接字可能要求进程拥有适当的权限才能使用 bind() 函数。

如果套接字的地址族是 AF_UNIX，应用程序应确保作为 sockaddr_un 结构的 address 的 sun_path 成员中包含路径名之后的空终止符，并且 address_len 至少为 offsetof(struct sockaddr_un, sun_path) + 1 加上路径名的长度。如果 address 的 sun_path 成员中的路径名指向一个现有文件（包括符号链接），bind() 应将此地址视为已被占用；参见下面的 ERRORS。

如果套接字地址无法立即分配，并且为套接字的文件描述符设置了 O_NONBLOCK，则 bind() 应失败并将 errno 设置为 [EINPROGRESS]，但分配请求不应被中止，分配应异步完成。在分配完成之前，针对同一套接字对 bind() 的后续调用应失败并将 errno 设置为 [EALREADY]。

当分配已异步执行时，pselect()、select()、poll() 和 ppoll() 应指示套接字的文件描述符已准备好进行读取和写入。

返回值 (RETURN VALUE)

成功完成后，bind() 应返回 0；否则，应返回 -1，并设置 errno 以指示错误。

错误 (ERRORS)

在以下情况下，bind() 函数应失败：

[EADDRINUSE]
指定的地址已被占用。
[EADDRNOTAVAIL]
指定的地址在本地机器上不可用。
[EAFNOSUPPORT]
对于指定套接字的地址族，指定的地址不是有效地址。
[EALREADY]
针对指定套接字的分配请求已在进行中。
[EBADF]
socket 参数不是有效的文件描述符。
[EINPROGRESS]
为套接字的文件描述符设置了 O_NONBLOCK，且分配无法立即执行；分配应异步执行。
[EINVAL]
套接字已绑定到某个地址，且协议不支持绑定到新地址；或套接字已被关闭。
[ENOBUFS]
可用于完成调用的资源不足。
[ENOTSOCK]
socket 参数不引用套接字。
[EOPNOTSUPP]
指定套接字的套接字类型不支持绑定到地址。

如果套接字的地址族是 AF_UNIX，则 bind() 在以下情况下应失败：

[EACCES]
路径前缀的某个组件拒绝搜索权限，或所请求的名称需要在模式拒绝写权限的目录中进行写入。
[EDESTADDRREQ] 或 [EISDIR]
address 参数是空指针。
[EILSEQ]
路径名的最后一个组件不是可移植文件名，且无法在目标目录中创建。
[EIO]
发生 I/O 错误。
[ELOOP]
在解析 address 中的路径名时遇到的符号链接中存在循环。
[ENAMETOOLONG]
路径名某个组件的长度长于 {NAME_MAX}。
[ENOENT]
address 中路径名的路径前缀的某个组件未指向现有文件，或路径名是空字符串。
[ENOENT] 或 [ENOTDIR]
address 中的路径名包含至少一个非 <slash> 字符，并以一个或多个尾随的 <slash> 字符结尾。如果去掉尾随的 <slash> 字符后的路径名会指向一个现有文件，则不应发生 [ENOENT] 错误。
[ENOTDIR]
address 中路径名的路径前缀的某个组件指向一个既不是目录也不是指向目录的符号链接的现有文件，或者 address 中的路径名包含至少一个非 <slash> 字符并以一个或多个尾随的 <slash> 字符结尾，且最后一个路径名组件指向一个既不是目录也不是指向目录的符号链接的现有文件。
[EROFS]
该名称将位于只读文件系统上。

在以下情况下，bind() 函数可以失败：

[EACCES]
指定的地址受保护，当前用户没有权限绑定到它。
[EINVAL]
address_len 参数对于该地址族不是有效长度。
[EISCONN]
套接字已连接。
[ELOOP]
在解析 address 中的路径名时遇到的符号链接超过 {SYMLOOP_MAX} 个。
[ENAMETOOLONG]
路径名的长度超过 {PATH_MAX}，或符号链接的路径名解析产生的中间结果的长度超过 {PATH_MAX}。
The following sections are informative.

示例 (EXAMPLES)

以下代码片段演示了如何创建套接字并将其绑定到 AF_UNIX 域中的名称。

#define MY_SOCK_PATH "/somepath"
 
int sfd;
struct sockaddr_un my_addr;
 
sfd = socket(AF_UNIX, SOCK_STREAM, 0);
if (sfd == -1)
    /* Handle error */;
 
memset(&my_addr, '\0', sizeof(struct sockaddr_un));
                     /* Clear structure */
my_addr.sun_family = AF_UNIX;
strncpy(my_addr.sun_path, MY_SOCK_PATH, sizeof(my_addr.sun_path) -1);
 
if (bind(sfd, (struct sockaddr *) &my_addr,
    sizeof(struct sockaddr_un)) == -1)
    /* Handle error */;

应用程序使用 (APPLICATION USAGE)

应用程序可以使用 getsockname() 函数检索已分配的套接字名称。

对于 AF_UNIX 套接字，某些实现支持一种扩展，其中 address_len 不必为存储在 sun_path 中的路径名包含空终止符，这反过来允许路径名长一个字节。但是，此类用法不可移植，并且存在访问超出路径名长度预期边界之外的风险。

理由 (RATIONALE)

鼓励实现使 bind() 在要绑定到 AF_UNIX 族套接字的地址的最后一个组件包含任何具有 <newline> 字符编码值的字节时报告 [EILSEQ] 错误。
