XSH 函数：snprintf()

名称 (NAME)

asprintf, dprintf, fprintf, printf, snprintf, sprintf — 打印格式化输出 (print formatted output)

提要 (SYNOPSIS)

#include <stdio.h>

[CX] int asprintf(char **restrict ptr, const char *restrict format, ...);
int dprintf(int fildes, const char *restrict format, ...);
int fprintf(FILE *restrict stream, const char *restrict format, ...);
int printf(const char *restrict format, ...);
int snprintf(char *restrict s, size_t n,
const char *restrict format, ...);
int sprintf(char *restrict s, const char *restrict format, ...);

说明 (DESCRIPTION)

[CX] Except for asprintf(), dprintf(), and the behavior of the %lc conversion when passed a null wide character, the functionality described on this reference page is aligned with the ISO C standard. Any other conflict between the requirements described here and the ISO C standard is unintentional. This volume of POSIX.1-2024 defers to the ISO C standard for all fprintf(), printf(), snprintf(), and sprintf() functionality except in relation to the %lc conversion when passed a null wide character.

fprintf() 函数应将输出放到指定的输出流上。printf() 函数应将输出放到标准输出流 stdout 上。sprintf() 函数应将输出及随后的空字节 '\0'，放到从 *s 开始的连续字节中；确保有足够空间可用是用户的责任。

[CX] asprintf() 函数应等同于 sprintf()，不同之处在于输出字符串应写入动态分配的内存中，该内存如同通过调用 malloc() 分配，长度足以容纳结果字符串（包括终止空字节）。如果对 asprintf() 的调用成功，此动态分配字符串的地址应存储在 ptr 所引用的位置中。

dprintf() 函数应等同于 fprintf() 函数，不同之处在于 dprintf() 应将输出写入与 fildes 参数指定的文件描述符相关联的文件，而不是将输出放到流上。

snprintf() 函数应等同于 sprintf()，外加 n 参数，该参数限制写入 s 所引用缓冲区的字节数。如果 n 为零，则不应写入任何内容，且 s 可以是空指针。否则，超出第 n-1 个的输出字节应被丢弃而不写入数组，并在实际写入数组的字节末尾写入一个空字节。

如果因调用 sprintf() 或 snprintf() 而在重叠的对象之间进行复制，则结果是未定义的。

这些函数中的每一个都在 format 的控制下转换、格式化并打印其参数。应用程序应确保 format 是一个字符串，在初始移位状态下开始和结束（如果有的话）。format 由零个或多个指令组成：普通字符（只是被复制到输出流）和转换说明（每一个都应导致取用零个或多个参数）。如果格式的参数不足，结果是未定义的。如果格式已用尽而仍有参数剩余，则多余参数应被求值但除此之外被忽略。

[CX] 转换可以应用于参数列表中 format 之后的第 n 个参数，而不是下一个未使用的参数。在这种情况下，转换说明符字符 %（见下文）被序列 "%n$" 替换，其中 n 是范围 [1,{NL_ARGMAX}] 内的十进制整数，给出参数在参数列表中的位置。此特性提供了定义按特定语言适宜的次序选择参数的格式字符串的能力（见 EXAMPLES 一节）。

format 可以包含编号参数转换说明（即由 "%n$" 引入并且可选地包含 "*m$" 形式的字段宽度和精度的那些），或未编号参数转换说明（即由 % 字符引入并且可选地包含 * 形式的字段宽度和精度的那些），但不能同时包含两者。唯一的例外是 %% 可以与 "%n$" 形式混合。在格式字符串中混合编号和未编号参数说明的结果是未定义的。当使用编号参数说明时，指定第 N 个参数要求从第一个到第 (N-1) 个的所有前导参数都在格式字符串中指定。

在包含 "%n$" 形式转换说明的格式字符串中，参数列表中的编号参数可以根据需要从格式字符串中引用任意多次。

在包含 % 形式转换说明的格式字符串中，每个转换说明使用参数列表中的第一个未使用参数。

[CX] 所有形式的 fprintf() 函数都允许在输出字符串中插入依赖语言的小数点字符。小数点字符在当前语言环境中定义（类别 LC_NUMERIC ). 在 POSIX 语言环境中，或在未定义小数点字符的语言环境中，小数点字符应默认为 <period>（'.'）。

每个转换说明由 '%' 字符 [CX] 或由字符序列 "%n$" 引入，之后按顺序出现以下内容：

  • 零个或多个标志（按任意顺序），它们修改转换说明的含义。

  • 一个可选的最小字段宽度。如果转换后的值字节数少于字段宽度，则默认应在左侧用 <space> 字符填充；如果给字段宽度指定了下文描述的左对齐标志（'-'），则应在右侧填充。字段宽度采用 <asterisk>（'*'）的形式，[CX] 或者在由 "%n$" 引入的转换说明中采用 "*m$" 字符串（ 下文描述）的形式，或十进制整数。

  • 一个可选的精度，它给出 d、i、o、u、x 和 X 转换说明符要出现的最小数字个数；a、A、e、E、f 和 F 转换说明符的小数点字符之后要出现的数字个数；g 和 G 转换说明符的最大有效数字个数；或者 s [XSI] 和 S 转换说明符中要从字符串打印的最大字节数。精度采用 <period>（'.'）后跟 <asterisk>（'*'）的形式，[CX] 或者在由 "%n$" 引入的转换说明中采用 "*m$" 字符串（ 下文描述）的形式，或可选的十进制数字字符串，其中空数字字符串视为零。如果精度与任何其他转换说明符一起出现，则行为是未定义的。

  • 一个可选的长度修饰符，指定参数的大小。

  • 一个转换说明符字符，指示要应用的转换类型。

字段宽度、精度或两者都可以用 <asterisk>（'*'）指示。在这种情况下，类型为 int 的参数提供字段宽度或精度。应用程序应确保指定字段宽度、精度或两者的参数按该顺序出现在要转换的参数（如果有）之前。负的字段宽度被视为 '-' 标志后跟正的字段宽度。负的精度被视为省略了精度。[CX] 在包含由 "%n$" 引入的转换说明的格式字符串中，除了用十进制数字字符串指示外，字段宽度还可以用序列 "*m$" 指示，精度用序列 ".*m$" 指示，其中 m 是范围 [1,{NL_ARGMAX}] 内的十进制整数，给出包含字段宽度或精度的整数参数在参数列表（format 参数之后）中的位置，例如：

printf("%1$d:%2$.*3$d:%4$.*3$d\n", hour, min, precision, sec);

标志字符及其含义是：

'
[CX] （<apostrophe>。）十进制转换（%i、%d、%u、%f、%F、%g 或 %G）结果的整数部分应用千位分组字符格式化。对于其他转换，行为是未定义的。使用非货币分组字符。
-
转换结果应在字段内左对齐。如果未指定此标志，则转换右对齐。
+
带符号转换的结果应始终以符号（'+' 或 '-'）开头。如果未指定此标志，则只有在转换负值时转换才以符号开头。
<space>
如果带符号转换的第一个字符不是符号，或者带符号转换不产生任何字符，则应在结果前加一个 <space>。这意味着如果 <space> 和 '+' 标志同时出现，则 <space> 标志应被忽略。
#
指定该值要转换为另一种形式。对于 o 转换，它应在必要且仅在必要时提高精度，以强制结果的第一个数字为零（如果值和精度都为 0，则打印单个 0）。对于 x 或 X 转换说明符，非零结果应在其前加 0x（或 0X）。对于 a、A、e、E、f、F、g 和 G 转换说明符，结果应始终包含小数点字符，即使小数点字符后没有数字也是如此。没有此标志时，只有在小数点字符后有数字时，这些转换的结果中才会出现小数点字符。对于 g 和 G 转换说明符，尾随零应不像通常那样从结果中删除。对于其他转换说明符，行为是未定义的。
0
对于 d、i、o、u、x、X、a、A、e、E、f、F、g 和 G 转换说明符，前导零（在符号或基数的任何指示之后）用于填充到字段宽度，而不是进行空格填充，除非在转换无穷大或 NaN 时。如果 '0' 和 '-' 标志同时出现，则 '0' 标志被忽略。对于 d、i、o、u、x 和 X 转换说明符，如果指定了精度，则 '0' 标志应被忽略。[CX] 如果 '0' 和 <apostrophe> 标志同时出现，则在零填充之前插入分组字符。对于其他转换，行为是未定义的。

长度修饰符及其含义是：

hh
指定随后的 d、i、o、u、x 或 X 转换说明符适用于 signed char 或 unsigned char 参数（该参数将已根据整数提升进行提升，但其值应在打印前转换为 signed char 或 unsigned char）；或者随后的 n 转换说明符适用于指向 signed char 参数的指针。
h
指定随后的 d、i、o、u、x 或 X 转换说明符适用于 short 或 unsigned short 参数（该参数将已根据整数提升进行提升，但其值应在打印前转换为 short 或 unsigned short）；或者随后的 n 转换说明符适用于指向 short 参数的指针。
l (ell)
指定随后的 d、i、o、u、x 或 X 转换说明符适用于 long 或 unsigned long 参数；随后的 n 转换说明符适用于指向 long 参数的指针；随后的 c 转换说明符适用于 wint_t 参数；随后的 s 转换说明符适用于指向 wchar_t 参数的指针；或者对随后的 a、A、e、E、f、F、g 或 G 转换说明符没有影响。
ll (ell-ell)
指定随后的 d、i、o、u、x 或 X 转换说明符适用于 long long 或 unsigned long long 参数；或者随后的 n 转换说明符适用于指向 long long 参数的指针。
j
指定随后的 d、i、o、u、x 或 X 转换说明符适用于 intmax_t 或 uintmax_t 参数；或者随后的 n 转换说明符适用于指向 intmax_t 参数的指针。
z
指定随后的 d、i、o、u、x 或 X 转换说明符适用于 size_t 或相应的有符号整数类型参数；或者随后的 n 转换说明符适用于指向与 size_t 参数对应的有符号整数类型的指针。
t
指定随后的 d、i、o、u、x 或 X 转换说明符适用于 ptrdiff_t 或相应的 unsigned 类型参数；或者随后的 n 转换说明符适用于指向 ptrdiff_t 参数的指针。
L
指定随后的 a、A、e、E、f、F、g 或 G 转换说明符适用于 long double 参数。

如果长度修饰符与上述指定之外的任何转换说明符一起出现，则行为是未定义的。

转换说明符及其含义是：

d, i
int 参数应转换为 "[-]dddd" 样式的带符号十进制数。精度指定要出现的最小数字个数；如果要转换的值可以用更少的数字表示，则应用前导零扩展。默认精度为 1。用显式精度 0 转换零的结果应是不产生任何字符。
o
unsigned 参数应转换为 "dddd" 样式的无符号八进制格式。精度指定要出现的最小数字个数；如果要转换的值可以用更少的数字表示，则应用前导零扩展。默认精度为 1。用显式精度 0 转换零的结果应是不产生任何字符。
u
unsigned 参数应转换为 "dddd" 样式的无符号十进制格式。精度指定要出现的最小数字个数；如果要转换的值可以用更少的数字表示，则应用前导零扩展。默认精度为 1。用显式精度 0 转换零的结果应是不产生任何字符。
x
unsigned 参数应转换为 "dddd" 样式的无符号十六进制格式；使用字母 "abcdef"。精度指定要出现的最小数字个数；如果要转换的值可以用更少的数字表示，则应用前导零扩展。默认精度为 1。用显式精度 0 转换零的结果应是不产生任何字符。
X
等同于 x 转换说明符，不同之处在于使用字母 "ABCDEF" 而不是 "abcdef"。
f, F
The double argument shall be converted to decimal notation in the style "[-]ddd.ddd", where the number of digits after the radix character is equal to the precision specification. If the precision is missing, it shall be taken as 6; if the precision is explicitly zero and no '#' flag is present, no radix character shall appear. If a radix character appears, at least one digit appears before it. The low-order digit shall be rounded in an implementation-defined manner.

表示无穷大的 double 参数应转换为 "[-]inf" 或 "[-]infinity" 样式之一；采用哪种样式是实现定义的。表示 NaN 的 double 参数应转换为 "[-]nan(n-char-sequence)" 或 "[-]nan" 样式之一；采用哪种样式以及任何 n-char-sequence 的含义是实现定义的。F 转换说明符分别产生 "INF"、"INFINITY" 或 "NAN"，而不是 "inf"、"infinity" 或 "nan"。

e, E
The double argument shall be converted in the style "[-]d.ddde±dd", where there is one digit before the radix character (which is non-zero if the argument is non-zero) and the number of digits after it is equal to the precision; if the precision is missing, it shall be taken as 6; if the precision is zero and no '#' flag is present, no radix character shall appear. The low-order digit shall be rounded in an implementation-defined manner. The E conversion specifier shall produce a number with 'E' instead of 'e' introducing the exponent. The exponent shall always contain at least two digits. If the value is zero, the exponent shall be zero.

表示无穷大或 NaN 的 double 参数应按照 f 或 F 转换说明符的样式转换。

g, G
The double argument representing a floating-point number shall be converted in the style f or e (or in the style F or E in the case of a G conversion specifier), depending on the value converted and the precision. Let P equal the precision if non-zero, 6 if the precision is omitted, or 1 if the precision is zero. Then, if a conversion with style E would have an exponent of X:

  • 如果 P>X>=-4，则转换应采用样式 f（或 F）和精度 P-(X+1)。

  • 否则，转换应采用样式 e（或 E）和精度 P-1。

最后，除非使用 '#' 标志，否则应从结果的小数部分删除任何尾随零，如果不再有小数部分，则应删除小数点字符。

表示无穷大或 NaN 的 double 参数应按照 f 或 F 转换说明符的样式转换。

a, A
A double argument representing a floating-point number shall be converted in the style "[-]0xh.hhhhp±d", where there is one hexadecimal digit (which shall be non-zero if the argument is a normalized floating-point number and is otherwise unspecified) before the decimal-point character and the number of hexadecimal digits after it is equal to the precision; if the precision is missing and FLT_RADIX is a power of 2, then the precision shall be sufficient for an exact representation of the value; if the precision is missing and FLT_RADIX is not a power of 2, then the precision shall be sufficient to distinguish values of type double, except that trailing zeros may be omitted; if the precision is zero and the '#' flag is not specified, no decimal-point character shall appear. The letters "abcdef" shall be used for a conversion and the letters "ABCDEF" for A conversion. The A conversion specifier produces a number with 'X' and 'P' instead of 'x' and 'p'. The exponent shall always contain at least one digit, and only as many more digits as necessary to represent the decimal exponent of 2. If the value is zero, the exponent shall be zero.

表示无穷大或 NaN 的 double 参数应按照 f 或 F 转换说明符的样式转换。

c
The int argument shall be converted to an unsigned char, and the resulting byte shall be written.

如果存在 l（ell）限定符，[CX] 则 wint_t 参数应转换为多字节序列，如同通过调用 wcrtomb() 一样，使用指向至少 MB_CUR_MAX 字节存储的指针，将 wint_t 参数转换为 wchar_t，并使用初始移位状态，然后写出得到的字节。

s
The argument shall be a pointer to an array of char. Bytes from the array shall be written up to (but not including) any terminating null byte. If the precision is specified, no more than that many bytes shall be written. If the precision is not specified or is greater than the size of the array, the application shall ensure that the array contains a null byte.

如果存在 l（ell）限定符，则参数应是指向类型为 wchar_t 的数组的指针。数组中的宽字符应转换为字符（每个字符都如同通过调用 wcrtomb() 函数一样，转换状态由在转换第一个宽字符之前初始化为零的 mbstate_t 对象描述），直到并包括终止空宽字符。得到的字符应被写出，直到（但不包括）终止空字符（字节）。如果未指定精度，应用程序应确保数组包含空宽字符。如果指定了精度，则写出的字符（字节）数不应超过该数量（包括移位序列（如果有）），并且如果为了等于精度给定的字符序列长度，函数需要访问数组末尾之后的一个宽字符，则数组应包含空宽字符。在任何情况下都不应写出部分字符。

p
参数应是指向 void 的指针。指针的值以实现定义的方式转换为可打印字符序列。
n
参数应是指向整数的指针，本次对某个 fprintf() 函数的调用到目前为止写入输出的字节数被写入该整数。不转换任何参数。
C
[XSI] 等同于 lc。
S
[XSI] 等同于 ls。
%
写出一个 '%' 字符；不应转换任何参数。应用程序应确保完整的转换说明是 %%。

如果转换说明与上述形式之一不匹配，则行为是未定义的。如果任何参数不是相应转换说明的正确类型，则行为是未定义的。

在任何情况下，不存在或太小的字段宽度都不应导致字段截断；如果转换结果比字段宽度宽，则字段应扩展以容纳转换结果。由 fprintf() 和 printf() 生成的字符的打印方式如同调用了 fputc() 一样。

对于 a 和 A 转换说明符，如果 FLT_RADIX 是 2 的幂，则该值应正确舍入为具有给定精度的十六进制浮点数。

对于 a 和 A 转换，如果 FLT_RADIX 不是 2 的幂，并且结果在给定精度下不能精确表示，则结果宜是给定精度的十六进制浮点样式中两个相邻数字之一，并附加规定：对于当前舍入方向，误差宜具有正确的符号。

对于 e、E、f、F、g 和 G 转换说明符，如果有效十进制数字个数至多为 DECIMAL_DIG，则结果宜被正确舍入。如果有效十进制数字个数多于 DECIMAL_DIG，但源值可以用 DECIMAL_DIG 个数字精确表示，则结果宜是带尾随零的精确表示。否则，源值以两个相邻的十进制字符串 L < U 为界，两者都有 DECIMAL_DIG 个有效数字；结果十进制字符串 D 的值宜满足 L <= D <= U，并附加规定：对于当前舍入方向，误差宜具有正确的符号。

[CX] 文件的最后数据修改和最后文件状态更改时间戳应被标记为待更新：

  1. 在成功执行 fprintf() 或 printf() 的调用与下一次对同一流调用 fflush() 或 fclose() 或调用 exit() 或 abort() 成功完成之间

  2. 在调用 dprintf() 成功完成时

返回值 (RETURN VALUE)

成功完成后，[CX] dprintf()、 fprintf() 和 printf() 函数应返回传输的字节数。

[CX] 成功完成后，asprintf() 函数应返回写入存储在 ptr 所引用位置中的已分配字符串的字节数，不包括终止空字节。

成功完成后，sprintf() 函数应返回写入 s 的字节数，不包括终止空字节。

成功完成后，snprintf() 函数应返回如果 n 足够大将会写入 s 的字节数，不包括终止空字节。

如果遇到错误，这些函数应返回负值 [CX] 并设置 errno 以指示错误。对于 asprintf()，如果无法分配内存，或者发生其他错误，函数应返回负值，并且 ptr 所引用位置的内容是未定义的，但不应指向已分配的内存。

如果在调用 snprintf() 时 n 的值为零，则不应写入任何内容，应返回如果 n 足够大将会写入的字节数（不包括终止空字节），并且 s 可以是空指针。

错误 (ERRORS)

关于 [CX] dprintf()、 fprintf() 和 printf() 失败及可能失败的条件，请参阅 fputc() 或 fputwc()。

[EILSEQ]

打印语言无关的日期和时间 (Printing Language-Independent Date and Time)

以下语句可用于使用语言无关的格式打印日期和时间：

printf(format, weekday, month, day, hour, min);

对于美式用法，format 可以是指向以下字符串的指针：

"%s, %s %d, %d:%.2d\n"

此示例将产生以下消息：

Sunday, July 3, 10:02

对于德式用法，format 可以是指向以下字符串的指针：

"%1$s, %3$d. %2$s, %4$d:%5$.2d\n"

format 的这种定义将产生以下消息：

Sonntag, 3. Juli, 10:02

打印宽字符 (Printing Wide Characters)

以下示例打印一系列宽字符。假设 "L`@`" 扩展为三个字节：

wchar_t wz [3] = L"@@";       // Zero-terminated
wchar_t wn [3] = L"@@@";      // Unterminated
 
fprintf (stdout,"%ls", wz);   // Outputs 6 bytes
fprintf (stdout,"%ls", wn);   // Undefined because wn has no terminator
fprintf (stdout,"%4ls", wz);  // Outputs 3 bytes
fprintf (stdout,"%4ls", wn);  // Outputs 3 bytes; no terminator needed
fprintf (stdout,"%9ls", wz);  // Outputs 6 bytes
fprintf (stdout,"%9ls", wn);  // Outputs 9 bytes; no terminator needed
fprintf (stdout,"%10ls", wz); // Outputs 6 bytes
fprintf (stdout,"%10ls", wn); // Undefined because wn has no terminator

在示例的最后一行中，处理三个字符后，已输出九个字节。然后必须检查第四个字符，以确定它转换为一个字节还是更多字节。如果它转换为多个字节，输出只有九个字节。由于数组中不存在第四个字符，行为是未定义的。

应用程序用法 (APPLICATION USAGE)

如果调用 fprintf() 的应用程序具有任何类型为 wint_t 或 wchar_t 的对象，它还必须包含 <wchar.h> 头文件，以便定义这些对象。

成功调用 asprintf() 分配的空间宜随后通过调用 free() 释放。

理由 (RATIONALE)

如果实现检测到格式的参数不足，建议函数应失败并报告 [EINVAL] 错误。

为 %lc 转换指定的行为与 ISO C 标准中的规范略有不同，区别在于打印空宽字符产生一个空字节，而不是 0 个输出字节——严格解读 ISO C 标准关于如同将 %ls 说明符应用于首元素为空宽字符的 wchar_t 数组那样行事的指示，会要求 0 字节输出。要求每个可能的宽字符（包括空字符）都产生多字节输出，符合历史实践，并且与 fprintf() 中的 %c 以及 fwprintf() 中的 %c 和 %lc 保持一致。预期未来版本的 ISO C 标准将更改以匹配此处指定的行为。
