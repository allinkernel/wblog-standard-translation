XSH 函数导读：chdir()

0. 总览

chdir() 用于更改当前工作目录。头文件为 <unistd.h>。原型：int chdir(const char *path)——唯一参数 path 指向要切换到的目录的路径名。

1. 机制

函数使 path 命名的目录成为当前工作目录，即不以 '/' 开头的路径名进行路径搜索的起始点。它只影响调用进程自己的工作目录，对其他进程没有影响。成功返回 0；失败返回 -1、设置 errno，并且当前工作目录保持不变。

2. 易错点

  • 必须检查返回值：失败时工作目录不变，若继续盲目做相对路径操作会落到错误的目录。
  • 常见错误码：路径前缀某组件被拒绝搜索权限 [EACCES]；组件不存在或 path 为空字符串 [ENOENT]；组件是文件而非目录 [ENOTDIR]；符号链接中存在循环 [ELOOP]；组件长于 {NAME_MAX} [ENAMETOOLONG]。
  • 符号链接会被解析到其目标目录，切换的是目标目录；同时注意 chdir() 只改变进程级工作目录，与 shell 的 cd 命令无关。

3. 示例

#include <unistd.h>
#include <stdio.h>

int main(void) {
    if (chdir("/tmp") == -1) {
        perror("chdir");
        return 1;
    }
    /* 之后所有相对路径均以 /tmp 为起点 */
    return 0;
}
