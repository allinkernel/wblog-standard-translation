XSH 函数：strtol()

名称 (NAME)

strtol、strtoll — 将字符串转换为长整数

提要 (SYNOPSIS)

#include <stdlib.h>

long strtol(const char *restrict nptr, char **restrict endptr, int base);
long long strtoll(const char *restrict nptr, char **restrict endptr,
int base)

说明 (DESCRIPTION)

[CX] The functionality described on this reference page is aligned with the ISO C standard. Any conflict between the requirements described here and the ISO C standard is unintentional. This volume of POSIX.1-2024 defers to the ISO C standard.

这些函数应分别将 nptr 所指向的字符串的初始部分转换为 long 和 long long 类型的表示。首先，它们将输入字符串分解为三个部分：

  1. 一个初始的、可能为空的空白字节序列

  2. 一个被解释为整数的主题序列，该整数以由 base 的值确定的某种基数表示

  3. 一个由一个或多个无法识别的字符组成的最终字符串，包括输入字符串的终止 NUL 字符。

然后它们应尝试将主题序列转换为整数，并返回结果。

如果 base 的值为 0，则主题序列的期望形式是十进制常量、八进制常量或十六进制常量，其中任何一个都可以在前面加上 '+' 或 '-' 符号。十进制常量以非零数字开头，并由一序列十进制数字组成。八进制常量由前缀 '0' 组成，其后可选地仅跟一序列数字 '0' 到 '7'。十六进制常量由前缀 0x 或 0X 组成，其后跟一序列十进制数字和字母 'a'（或 'A'）到 'f'（或 'F'），其值分别为 10 到 15。

如果 base 的值在 2 到 36 之间，则主题序列的期望形式是一序列字母和数字，表示以 base 指定的基数表示的整数，可选地在其前面加上 '+' 或 '-' 符号。从 'a'（或 'A'）到 'z'（或 'Z'）（含）的字母被赋予值 10 到 35；只允许使用其被赋予的值小于 base 的值的字母。如果 base 的值为 16，则字符 0x 或 0X 可以可选地放在字母和数字序列之前，位于符号（如果存在）之后。

主题序列被定义为输入字符串的、以第一个非空白字节开始的、具有期望形式的最长初始子序列。如果输入字符串为空或完全由空白字节组成，或者第一个非空白字节不是符号或允许的字母或数字，则主题序列应不包含任何字符。

如果主题序列具有期望形式且 base 的值为 0，则以第一个数字开始的字符序列应被解释为整数常量。如果主题序列具有期望形式且 base 的值在 2 到 36 之间，则它应被用作转换的基数，按上述为每个字母赋予其值。如果主题序列以 <hyphen-minus> 开头，则结果值应为转换值的相反数。指向最终字符串的指针应存储在 endptr 所指向的对象中，前提是 endptr 不是空指针。

在 C [CX] 或 POSIX 语言环境以外的语言环境中，可以接受额外的特定于语言环境的主题序列形式。

如果主题序列为空或不具有期望形式，则不执行转换；nptr 的值应存储在 endptr 所指向的对象中，前提是 endptr 不是空指针。

这些函数在成功时不应改变 errno 的设置。

由于 0、{LONG_MIN} 或 {LLONG_MIN}、{LONG_MAX} 或 {LLONG_MAX} 在出错时被返回，并且也是成功时的有效返回值，希望检查错误情况的应用程序宜将 errno 设置为 0，然后调用 strtol() 或 strtoll()，然后检查 errno。

返回值 (RETURN VALUE)

成功完成后，这些函数应返回转换后的值（如果有）。如果无法执行任何转换，则应返回 0 [CX] 并且 errno 可以被设置为 [EINVAL]。

[CX] 如果 base 的值不受支持，则应返回 0，并且 errno 应被设置为 [EINVAL]。

如果正确的值超出可表示值的范围，则应返回 {LONG_MIN}、{LONG_MAX}、{LLONG_MIN} 或 {LLONG_MAX}（根据值的符号），并将 errno 设置为 [ERANGE]。

错误 (ERRORS)

在以下情况下，这些函数应失败：

[EINVAL]
[CX] base 的值不受支持。
[ERANGE]
要返回的值不可表示。

在以下情况下，这些函数可以失败：

[EINVAL]
无法执行任何转换。
The following sections are informative.

示例 (EXAMPLES)

无。

应用程序使用 (APPLICATION USAGE)

由于如果 base 的值不受支持，*endptr 的值是未指定的，因此应用程序宜在调用前确保 base 具有受支持的值（0 或 2 到 36 之间），或者在检查 *endptr 之前检查 [EINVAL] 错误。
