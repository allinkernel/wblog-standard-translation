XSH 函数导读：pthread_once()

0. 总览

pthread_once() 保证进程内给定的初始化例程只被执行一次，用于多线程场景下的动态包初始化。头文件为 <pthread.h>。原型关键点：int pthread_once(pthread_once_t *once_control, void (*init_routine)(void));——控制对象需用 PTHREAD_ONCE_INIT 静态初始化，成功返回零。

1. 机制

进程中任何线程对同一个 once_control 的第一次调用会执行 init_routine，后续所有调用都不再执行；从 pthread_once() 返回时，init_routine 一定已经完成，所以"先到者执行、后到者等待"由实现保证。它本身不是取消点，但若 init_routine 是取消点并被取消，对 once_control 的影响视同从未调用过 pthread_once()，即下次调用会重新执行初始化。它取代了"检查静态标志 + 互斥量"的手工写法，是线程安全的一次性初始化原语。

2. 易错点

once_control 必须具有静态存储期且由 PTHREAD_ONCE_INIT 初始化：使用自动存储期或未初始化对象行为未定义。不要在 init_routine 里用同一 once_control 递归调用 pthread_once()，那会死锁——递归调用不会执行例程、也不会返回。不要在 init_routine 中 longjmp/siglongjmp 跳出，行为未定义。不要复制或重用 once_control 值，其内部状态由实现私有持有。

3. 示例

#include <pthread.h>
#include <stdio.h>

static pthread_once_t once = PTHREAD_ONCE_INIT;

static void init_random(void) {
    printf("初始化只执行一次\n");
}

void *worker(void *arg) {
    pthread_once(&once, init_random);   /* 多个线程并发调用 */
    return NULL;
}

int main(void) {
    pthread_t t1, t2;
    pthread_create(&t1, NULL, worker, NULL);
    pthread_create(&t2, NULL, worker, NULL);
    pthread_join(t1, NULL);
    pthread_join(t2, NULL);
    return 0;
}
