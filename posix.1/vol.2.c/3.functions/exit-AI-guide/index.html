XSH 函数导读：exit()

0. 总览

exit() 终止进程，并完成正常进程终止所需的收尾动作。它声明于 <stdlib.h>，原型为 void exit(int status);，且不返回。status 可以是 0、EXIT_SUCCESS、EXIT_FAILURE 或任何其他值，但只有最低有效的 8 位（status & 0377）可从 wait() 和 waitpid() 获得；完整值可从 waitid() 以及传递给 SIGCHLD 信号处理器的 siginfo_t 中获得。

1. 机制

exit() 首先按注册的相反顺序调用所有由 atexit() 注册的函数；若某个注册函数未能返回，则其余注册的函数不再被调用，exit() 处理的其余部分也不完成。随后它刷新所有具有未写入缓冲数据的打开流，并对每个打开的流执行等效的 close()。最后进程被终止，产生与"进程终止的后果"相同的后果：生成状态信息、进程转为僵尸进程直至父进程获得其状态信息、向父进程发送 SIGCHLD 等。从 main() 返回等价于以该返回值调用 exit()。

2. 易错点

多次调用 exit()，或除 exit() 之外还调用 quick_exit()，行为未定义——因此不要在 atexit 注册的函数里再调用 exit()；如需停止进一步处理应调用 _exit() 或 _Exit()。exit() 与 _exit() 的关键区别在于：_exit() 不调用 atexit 注册的函数、不刷新流。exit() 刷新流时调用进程无法得知写入是否成功，建议先显式 fflush(stdout) 并检查 ferror() 再以相应状态退出，否则可能出现"已按成功退出但输出丢失"。在信号处理器中调用 exit() 并不安全，应避免。

3. 示例

#include <stdlib.h>
#include <stdio.h>

int main(void) {
    if (fflush(stdout) != 0)
        return EXIT_FAILURE;
    return EXIT_SUCCESS;   /* 等价于 exit(EXIT_SUCCESS) */
}
