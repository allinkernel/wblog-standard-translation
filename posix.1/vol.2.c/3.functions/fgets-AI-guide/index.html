XSH 函数导读：fgets()

0. 总览

fgets() 从流中获取字符串：读取字节直到读满 n-1 个、读到并传送一个 <newline>、或遇到文件末尾条件。头文件为 <stdio.h>。原型关键点：char *fgets(char *restrict s, int n, FILE *restrict stream)——成功返回 s，读到文件末尾或出错返回空指针。

1. 机制

读取在三种情况下停止：已读 n-1 个字节、读到一个换行符（换行符会被传送到 s）、或遇到文件末尾条件。在写入数组的最后一个字节之后，立即写入一个空字节，因此 s 至少需要容纳 n 个字节（含结尾空字节）。如果在读取任何字节之前就遇到文件末尾，则 s 指向的数组内容不被改变，函数返回空指针并设置流的文件末尾指示符；发生错误时设置错误指示符、设置 errno，同样返回空指针。

2. 易错点

  • 保留换行：换行符被保留在结果字符串中，处理前需要自行去除（例如用 strcspn(s, "\n") 找到并截断）；gets() 不含换行，二者行为不同。
  • 返回空指针不代表出错：可能是读到文件末尾（feof()），也可能是错误（ferror()），需用 feof()/ferror() 区分。
  • 行长超过 n-1 时不会一次读完：返回值非空但整行没有读完，需要检查读到的最后一个字节是否为换行符；下一轮循环会继续读该行的剩余部分。
  • 缓冲大小要留出空字节位置：若缓冲区为 N 字节，n 最多传 N，实际最多读入 N-1 个字节。
  • 避免与 gets() 混淆——gets() 不检查长度，属于经典缓冲区溢出来源，应使用 fgets() 或 getline()。

3. 示例

#include <stdio.h>
#include <string.h>

int main(void)
{
    char line[256];
    size_t len;

    while (fgets(line, sizeof(line), stdin) != NULL) {
        len = strlen(line);
        if (len > 0 && line[len - 1] == '\n')
            line[--len] = '\0';      /* 去掉 fgets 保留的换行 */
        else
            ; /* 数组已满且无换行：行未读完，需继续读取 */
        printf("[%s]\n", line);
    }
    return 0;
}
