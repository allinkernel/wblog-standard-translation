XSH 函数：ftruncate()

名称 (NAME)

ftruncate — 将文件截断为指定长度 (truncate a file to a specified length)

摘要 (SYNOPSIS)

#include <unistd.h>

int ftruncate(int fildes, off_t length);

说明 (DESCRIPTION)

如果 fildes 不是为写入而打开的有效文件描述符，则 ftruncate() 函数应失败。

如果 fildes 指代一个普通文件，ftruncate() 函数应使文件的大小被截断为 length。如果文件的大小先前超过 length，多余的数据应不再对文件的读取可用。如果文件先前小于该大小，ftruncate() 应增大文件的大小。如果文件大小被增大，扩展的区域应看起来像是被零填充的。调用 ftruncate() 不应修改查找指针的值。

成功完成后，如果 fildes 指代一个普通文件，ftruncate() 应标记文件的最后数据修改和最后文件状态更改时间戳以进行更新，并且文件模式的 S_ISUID 和 S_ISGID 位可以被清除。如果 ftruncate() 函数不成功，文件不受影响。

如果请求将导致文件大小超过进程的软文件大小限制，请求应失败 [XSI] 并且实现应为该线程生成 SIGXFSZ 信号。

如果 fildes 是为写入而打开的文件描述符，且指代既不是普通文件也不是共享内存对象的文件，则结果是未指定的。

[SHM] 如果 fildes 指代一个共享内存对象，ftruncate() 应将共享内存对象的大小设置为 length。

如果 ftruncate() 的效果是减小内存映射文件 [SHM] 或共享内存对象 的大小，并且先前映射了超出新末尾的整页，则超出新末尾的整页应被丢弃。

对已丢弃页面的引用应导致生成 SIGBUS 信号。

如果 ftruncate() 的效果是增大内存对象的大小，则旧文件末尾与新末尾之间的任何映射页面的内容是否被刷新到底层对象是未指定的。

返回值 (RETURN VALUE)

成功完成后，ftruncate() 应返回 0；否则，应返回 -1 并设置 errno 以指示错误。

错误 (ERRORS)

如果满足以下条件，ftruncate() 函数应失败：

[EBADF] 或 [EINVAL]
fildes 参数不是为写入而打开的文件描述符。
[EFBIG] 或 [EINVAL]
length 参数大于最大文件大小。
[EFBIG]
length 参数超过进程的文件大小限制。[XSI] 还应为该线程生成 SIGXFSZ 信号。
[EFBIG]
该文件是普通文件，且 length 大于与 fildes 关联的打开文件描述中确定的偏移最大值。
[EINTR]
执行期间捕获到一个信号。
[EINVAL]
length 参数小于 0，或者 fildes 参数指代一个无法执行此操作的文件（例如，管道、FIFO 或套接字）。
[EIO]
从文件系统读取或向文件系统写入时发生了 I/O 错误。

变更历史 (CHANGE HISTORY)

首次发布于第 4 版第 2 版次。

第 5 版 (Issue 5)

从 X/OPEN UNIX 扩展移至 BASE（基础），并与 POSIX 实时扩展中的 ftruncate() 保持一致。具体来说，DESCRIPTION（说明）被大量改写，并且 [EROFS] 被添加到 ftruncate() 可以返回的强制性错误列表中。

添加了 Large File Summit 扩展。

第 6 版 (Issue 6)

truncate() 函数被拆分到单独的参考页中。

对 POSIX 实现的以下新要求源自与单一 UNIX 规范（Single UNIX Specification）的一致性：

  • DESCRIPTION（说明）被更改，以表明如果文件大小被更改，且文件是普通文件，则文件模式中的 S_ISUID 和 S_ISGID 位可以被清除。

进行了以下更改，以与 IEEE P1003.1a 草案标准保持一致：

  • DESCRIPTION（说明）文本已更新。

符合 XSI 的系统被要求：如果文件先前小于请求的大小，则增大文件的大小。

第 7 版 (Issue 7)

应用了 Austin Group 解释 1003.1-2001 #056，修订了 ERRORS（错误）部分（尽管 [EINVAL] 的 "可以失败" 错误后来在审查 XSI 选项期间被移除）。

与内存保护和内存映射文件选项相关的功能被移至 Base（基础）。

DESCRIPTION（说明）已更新，使得当文件小于请求的大小时调用 ftruncate() 将增大文件的大小。以前，不符合 XSI 的实现被允许增大文件的大小或失败。

进行了与细粒度时间戳支持相关的更改。

第 8 版 (Issue 8)

应用了 Austin Group 缺陷 308，澄清了 [EFBIG] 错误的处理。

应用了 Austin Group 缺陷 1169，移除了关于如果 fildes 指代目录则 ftruncate() 失败的冗余陈述。

应用了 Austin Group 缺陷 1381，为 [EINVAL] 错误添加了第二个条件，并将 ERRORS（错误）部分重新排列为字母顺序。

应用了 Austin Group 缺陷 1669，从与进程的文件大小限制相关的部分 [EFBIG] 错误中移除了 XSI 阴影标记。
